# 参考货物品类原创美术

按用户要求参考中华铁路的货物种类，首批24种，仅扩充订单名称与美术，沿用现有经营规则。

- `cargo-food-atlas-v1.png`：牛排、草莓、西瓜、雪花梨、苹果、葡萄、大米、鲜鱼。
- `cargo-everyday-atlas-v1.png`：旅行箱、针织衫、方便面、毛绒玩具、电脑、木箱、邮政包裹、旅行袋。
- `cargo-special-atlas-v1.png`：石油、煤炭、宝石、药品、救灾物资、酒类、羊驼、白色货箱。

每张1774×887、RGBA透明，按上排从左到右、下排从左到右排列。均为内置 image_gen 原创绘制，`prompts.json` 保存完整提示词，`catalog.json` 保存来源哈希、原作货物编号和实际裁切边界。实际轮廓可能跨越均分网格，因此运行时使用逐件坐标。

原图未重编码，原样复制进 `public/art/`；SVG仅选取图集中的对应区域。不拆单张PNG，不使用APK原素材。既有库存物资保持真实名称；货名只作只读展示，不改变服务费率、舱型限制或存档字段。
