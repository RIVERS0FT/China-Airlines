# 飞机完整外观资源

当前每架飞机保留一张独立的 1536×590 透明 RGBA、严格左向侧视图。对应现实原型、游戏容量和文件名在 `manifest.json` 中；只使用原创蓝白金涂装，不加入现实航空公司标记、注册号、文字或人物。

新增或重绘时直接交付一张完整封闭外观图。保持机头、机翼、发动机、起落架、尾部以及飞机类型的识别特征完整。不得在图内预画舱内结构、座椅、货盘、人物或货物，也不创建剖面图、近侧蒙皮图和上下双图母版。

程序化机舱的坐标、基础容量槽位和分区记录在 `src/ui/aircraft-cabin-layouts.json`。`npm run art:verify` 检查源图与运行图逐像素一致、画布尺寸和透明四角。新机型的现实原型和容量依据须按 `docs/AIRCRAFT-REALISM.md` 补齐。
