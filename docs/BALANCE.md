# 适中经营数值平衡

## 目标与边界

前期能购置第二架飞机或开出第三座机场，中后期以持续运输积累扩张资金。以下为本作航空化平衡值，不是《中华铁路》的完整数值复刻。

起始资金18,000金币、24点券；仅拥有北京1级基地，机队为空。上海机场售价4,000，钻石DA40售价2,300。当前v14只接受本版存档；旧版本主档与备份保留，确认重新开始后才新建。

## 收入与运行成本

以DESIGN.md公式为准。编队每级增加基础收入20%、运行成本12%；进化每级增加收益1.5%，满编队和满进化收入为基础的2.86倍。成本由每距离单位的额定容量运营费、重量/速度项，以及每次起飞每额定格12金币的处理费组成。空配、空载和少装不能免除机体成本；转机增加处理费但不能重复付运费。

## 购机免费选配

点击购买后必须在选配框中指定客位和货位，至少一格、最多机型总容量，可保留空格。确认时一次性校验选配、资金、机位与交付条件，只扣机价并交付配置好的飞机；关闭、取消或刷新未确认的选配，不会购买飞机。免费仅属于本次购机选配，之后改装按原价收费，卸空、封存、恢复、刷新或导入均不产生免费次数。组装机不受此购机流程影响，仍按现有规则付费配置。

## 成长、组装与奖励

- 下一编队等级n的金币费：机价×20%×n^1.5，向上取整到100金币；进化费：机价×8%×n，向上取整到100金币。两者另收2n点券、n机身组件、n动力组件；电力仍为500n金币与2n点券。
- 编队上限6、进化上限20，进化需要编队至少2级。UI和核心共用成长报价。
- 零件组装金币费从机价30%调至60%，零件与点券要求不变；出售裸机仍返机价50%，杜绝组装后直接卖出套利。
- 三机场两项任务合计金币奖励由6,000降为3,000（运营1,200＋成长1,800），少于最便宜新机场价格；十航班合计由11,000降为5,500（运营3,000＋成长2,500）。首航仍奖1,500，避免初期缺乏正反馈。
- 机场1→2级8,000金币、2→3级24,000金币；购机等级及两端机场等级要求继续生效。
