# 球形航网与世界机场

> 2026-09-13：入口行为以 [DESIGN.md](DESIGN.md) 的“地图浏览与制定路线分离”为准。下文发航控件仅适用于“制定路线”；“地图”用于城市浏览与解锁。

## 替换规则与保留边界

本轮依据“游戏地图改为球形，允许世界范围机场”替换 MAP-LAYOUT.md 的960×630平面、装饰地形、平移相机和像素航程圈。保留2D场景与PixiJS 8渲染，航网采用可交互的正射球面投影：不是一张圆形裁切的平面地图，也不引入Three.js、外部瓦片、实时地图服务或网络字体。

继承独立发航页的四项读数、地图高度至少85%、44px主要操作、最多5段顺序选路、按需城市与路线窗口、取消返回原飞机/机场、真实订单、逐段能量与核心唯一写入者。全球选择不代表任意飞机可直飞；航程、机场等级、资金、补能/周转/值勤约束全部保留。不修改后台/离线结算、运行控制器、持久化实现和既有CI/Pages工作流。

## 球面交互与渲染

2026-09-14 的美术升级只修改球体本身：海洋采用深青蓝明暗层次，陆地按朝向使用森林绿至暖橄榄色光照，离线三角网格的外边生成海岸暗边与浅色沿岸线，经纬网区分赤道，并增加明暗两侧的大气边缘。页面原有径向地图背景保持原样，不用新图片替换。航线沿原最短大圆方向绘制，但高度使用两端贴地、中段抬升的二次抛物线；飞机沿同一抛物线位置移动，并按实际 `modelId` 使用本地机型图，替换旧三角标记。飞行中机头沿屏幕航迹切线指向下一位置，按东西向自动水平镜像，并把机身旋转限制在正立半周，避免倒飞或倒置。新增效果仍按需重建或随可见航班以最高30fps更新，不引入纹理下载、持续背景动画或新的经营写入。

2026-09-14 斜线修复：地球外圈、亮侧圆弧和暗侧圆弧必须是独立描边路径。每段圆弧先 `beginPath()`，再 `moveTo()` 到按当前圆心、半径和起始角计算的真实起点，最后绘弧和描边；不能从画布原点或上一段端点连接到新圆弧。由 `globe-atmosphere.ts` 统一重建，浏览地图与制定路线共用；旋转、缩放和尺寸改变后仍必须满足此约束。保留原颜色、透明度、线宽、角度、半径偏移和球体外背景，不用遮盖背景或删除正常航线掩盖问题。该修复不修改经营规则、存档、依赖或部署流程。

对应回归使用真实 PixiJS `GraphicsContext` 展开两段圆弧，检查各自起止点、圆周距离、连续短段、重绘不累积及旧原点连线复现；浏览器在1440×900、844×390、667×375分别检查浏览与制定路线，比较初始及旋转缩放后原斜线区域与未绘制画布的背景像素，保存截图。其余触控、航线、按需重绘、存档和离线回归继续执行；检查实际结果以 PR 的 Verify 记录为准，不将测试定义视为通过回执。

机场由经纬度投影，旋转同时改变陆地、机场、航迹和航程圈；球体背面的机场与飞机不显示也不参与命中。拖动旋转、滚轮/双指缩放，缩放1—6倍；方向键旋转，Home或点当前飞机定位。双指结束、pointercancel和拖动结束不追加城市。缩放和旋转只保存在视图，不修改经营状态。

世界视图优先展示完整球体；放大后可以看局部。标记与中文标签使用屏幕像素尺寸，不随球体缩小；重叠标签按选中、草稿、当前飞机、已开放、未开放的优先级避让。标签隐去不删除机场，顶部原生选择器始终能访问全部50座机场。窗口打开/关闭与时钟推进不重置球面朝向；重新进入地图才重新定位实际飞机。

航迹和飞机沿经纬度确定的最短大圆路径绘制，跨180度经线不绕远、不画穿球直线。对跖点采用确定性的等长路径；同点、极点及地平线裁切不能产生NaN。范围圈使用与核心相同的6371 km球半径和实际机型航程，围绕草稿末站绘制球面等距圈；像素误差与核心距离取整仍意味着它只是提示。背面航迹在地平线裁切，不用弦连接不可见段。

地形仅在相机改变时重建；机场文字对象复用。主渲染器按需绘制：静止球体不因时钟推进重复重绘，镜头、路线、客货或机队状态改变才重绘；可见飞行的动画上限30fps，动画仍只读已锁定航班。页面能量、收益、时间和装载逻辑不因投影变化改变。

## 首批50座机场

保留原12座机场全部代码、坐标与经济配置，新增38座，覆盖亚洲、欧洲、非洲、北美洲、南美洲及大洋洲，并包含安克雷奇、檀香山、雷克雅未克、楠迪等跨洋中转节点。所有机场可经现有8000 km机型分段联通；不增加无限航程机型。

初始仍只开放PEK、PVG。新增机场按配置价格解锁、按原规则升级和产生真实候运订单，可以装载、派航、自动往返、多段运输、补能和保存。不会因浏览全球而自动解锁、移动飞机、重发订单或赠送收入。首批不是全球所有真实机场，也不表示真实机场运行状态。

配置统一在core目录：world-airports.ts是可扩展清单，catalog.ts合并本地与世界配置。经纬度为0.1度级游戏近似；价格、需求系数为暂定游戏平衡值，不是真实费用或已核实的原版数值。城市/代码/区域/大洲关键词可组合检索，机场目录支持大洲筛选并保留本次页面浏览上下文。城市选择器保留原生select，WebGL失败和缓存离线启动时仍能操作。

## 存档与校验

包版本仍0.5.0，保存格式升为6，IndexedDB结构仍1，依赖与锁文件不变。数据库结构版本不等于保存格式版本。原v1—v4严格校验后迁移到6，沿用原迁移语义；v5先通过独立冻结校验，再只更改version为6。v5校验冻结最新已发布主分支5b79d57的完整v5规则与catalog-v5，兼容原聚合订单/云雀70和单体订单/云雀6两种v5历史：不放宽旧机场枚举，不重算任何订单、账目、预留能量、补能截止时间或在途时刻，不重复赠能。

v6基础设施校验使用世界目录，机场数上限等于目录数量，唯一无向航线记录上限为N×(N−1)/2（当前1225），不再误用旧66条上限。未知/重复机场、无效等级、错误引用、额外字段、损坏数字、无效航程/计划/订单和能量都必须拒绝；旧版伪造世界机场的存档仍被拒绝。原始存档失败不覆盖和备份恢复规则不变，文件上限仍1MB。

## 地形来源与许可

离线陆地网格源自Natural Earth低分辨率陆地轮廓（本次使用环境内pyogrio测试夹具naturalearth_lowres，177个要素），先溶解国界，再以1度简化、15度网格分割、约束三角化、0.1度量化。只保留1395个坐标和1225个三角形；没有行政边界、人口、国名或在线下载。数据版本仅以所用夹具及输出为准，不宣称最新测绘资料。小岛和海岸会被简化，机场标记不依赖小岛是否保留。

Natural Earth公开许可说明：https://www.naturalearthdata.com/about/terms-of-use/ ，其地图数据为公有领域。机场近似坐标仅为游戏配置；可参考公开字段说明 https://ourairports.com/data/ 。不包含其他游戏商标、地图图片、代码或音效。
