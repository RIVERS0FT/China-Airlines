# 地图浏览：独立按钮与触控穿透（2026-09-14）

## 跨页面导航增量（2026-09-15）

当前导航坐标、按钮尺寸及左对齐规则以 [NAVIGATION-LAYOUT.md](NAVIGATION-LAYOUT.md) 为准：机场、地图和公司组织使用相同的导航几何；地图仍不占画布高度、不显示底栏背景、不阻断空白区域触控。该增量替换下文“机场导航高度不受此改动影响”的阶段约定，以及此前只对地图设置独立左下角坐标的实现。

## 替换旧约定

浏览页不显示工具栏、右上角查找城市按钮、底部背景、地图标题说明或可视放大/缩小按钮。保留顶部公司/资金/机队/点券/帮助/存档状态栏；返回机场使用底部“机场装载”，语言和显示比例仍从存档设置进入。正常地图直接点击城市；WebGL 失败时通过替代城市列表搜索、查看和解锁城市。资金只显示一份。

地图、机场装载、机场目录、机队管理、飞机商店、公司组织、经营中心七个按钮左对齐悬浮于左下角。导航容器不在布局流中，无背景、边框、阴影或伪元素，不撑出底栏；容器不接收指针，只有按钮本体接收点击。按钮之间与右侧空白处的点击、拖动、滚轮及多指事件直接进入地图。机场装载页面的队列和导航高度不受此改动影响。

## 地图、标签与制定航线

地图画布从资源栏下方一直延伸至页面底边，不为底部导航预留高度。“点城市查看详情与解锁”常驻提示移除，城市点击、详情和解锁行为保留。标签的裁切边界恢复到真实画布底边，仅避让实际导航按钮的矩形，不再为已删除提示保留空位。矩形通过物理边界换算为逻辑像素，窗口、UI缩放或导航尺寸变化时重新测量；不改变相机、选中城市、订单或航班。标签数据属性仅供渲染诊断与浏览器断言。

城市名称、等级详情和客源标记作为整体使用相对机场点的布局偏移（`dx/dy`）。标签屏幕位置每帧由机场点当前投影加上该偏移得到，拖动、旋转和缩放时与机场点同步跟手，不对相机造成的位置变化插值。只有碰撞避让切换相对偏移时，才作160 ms二次缓出插值（`1 - (1 - t)^2`）；新的避让目标从当前采样偏移重定向，内容宽高立即按新文字更新。点击命中继续使用当前球面投影；标签首次出现或重新出现直接放在目标位置，机场进入背面或无合法目标时立即隐藏并清理过渡状态。减少动态效果开启时取消偏移过渡并直接到位；过渡完成且没有可见飞行时停止额外重绘，保持静止地图按需绘制。

目标偏移沿用现有标签互避与安全区规则。偏移插值后的屏幕位置如果越出安全区或与导航等覆盖控件相交，直接移至合法目标，保证按钮与边缘可读；不同标签的中间路径允许短暂交叉，不为此反复跳位，最终目标仍保持互避。

移除放大和缩小按钮后，双指捏合、滚轮、键盘加减与方向键仍保留。制定航线的后退/撤销/取消/查看按钮向左收齐，不留原缩放按钮空位。“隐藏其他飞机”仅在制定航线显示并位于路线按钮上方，仅改变渲染；浏览地图始终显示其他在途飞机，不继承规划时的隐藏状态。制定航线的独立读数、检票、航程圈、客源标记及原标签安全区保持。

## 验收

纯几何测试覆盖缩放换算、底部空白可用、按钮避让、标签间隔与边界。浏览器覆盖桌面及两种手机横屏、150%缩放，检查画布延伸、按钮左对齐、容器无底色、间隙与右侧空白命中画布、底部拖动和捏合、底部标签可见及不覆盖按钮；标签专项检查相机移动时名称与机场点同步、仅避让偏移存在中间位置、最终收敛停绘、首次直接定位、背面立即隐藏、减少动态效果直接到位，以及点击不受偏移插值影响。保留浏览解锁/取消、在途返回、规划隐藏飞机、英文搜索、无WebGL、导入/导出、刷新恢复与离线启动回归。

单项修改执行类型检查、对应路径构建和受影响的定向测试；推送时执行全部核心、持久化和资源测试，以及一次相对路径构建和一次全量浏览器流程，详见 [测试约定](TESTING.md)。最终结果以当前提交的运行回执为准，不将缓存产物或未运行检查视作本次通过。
