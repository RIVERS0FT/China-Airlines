# 地图浏览：独立按钮与触控穿透（2026-09-14）

## 替换旧约定

按本轮截图要求替换浏览页的整条工具栏、整条底部背景，以及所有地图的可视放大/缩小按钮。保留顶部公司/资金/机队/点券/帮助/存档状态栏；返回机场改用底部“机场装载”，语言和显示比例仍从存档设置进入。查找城市保留为右上角独立按钮，WebGL失败时仍能搜索、查看和解锁城市。已解锁数量放在左上角航网提示下，资金只显示一份。

地图、机场装载、机场目录、机队管理、飞机商店、经营中心六个按钮左对齐悬浮于左下角。导航容器不在布局流中，无背景、边框、阴影或伪元素，不撑出底栏；容器不接收指针，只有按钮本体接收点击。按钮之间与右侧空白处的点击、拖动、滚轮及多指事件直接进入地图。机场装载页面的队列和导航高度不受此改动影响。

## 地图、标签与制定路线

地图画布从资源栏下方一直延伸至页面底边，不为底部导航预留高度。标签的裁切边界恢复到真实画布底边，采用实际按钮及装饰提示的矩形避让，而不是整条底部禁区。矩形通过物理边界换算为逻辑像素，窗口、UI缩放、导航或提示尺寸变化时重新测量；不改变相机、选中城市、订单或航班。标签数据属性仅供渲染诊断与浏览器断言。

移除放大和缩小按钮后，双指捏合、滚轮、键盘加减与方向键仍保留。制定路线的后退/撤销/取消/查看按钮向左收齐，不留原缩放按钮空位。“隐藏其他飞机”仅在制定路线显示并位于路线按钮上方，仅改变渲染；浏览地图始终显示其他在途飞机，不继承规划时的隐藏状态。制定路线的独立读数、检票、航程圈、客源标记及原标签安全区保持。

## 验收

新增纯几何测试覆盖缩放换算、底部空白可用、按钮避让、标签间隔与边界。浏览器覆盖桌面及两种手机横屏、150%缩放，检查画布延伸、按钮左对齐、容器无底色、间隙与右侧空白命中画布、底部拖动和捏合、底部标签可见及不覆盖按钮。保留浏览解锁/取消、在途返回、规划隐藏飞机、英文搜索、无WebGL、导入/导出、刷新恢复与离线启动回归。
