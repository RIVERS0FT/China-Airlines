# 飞机外观与程序化机舱规则

每架当前飞机保留一张独立的 1536×590 透明 RGBA 左向完整外观图，采用对应现实原型的结构与原创蓝白金涂装。外观图不得预绘乘客、货物、座椅、货盘、订单或按钮。新增机型只需提供完整外观图和容量布局，不生成剖面图、近侧蒙皮图或双图母版。

机场装载页使用同一张外观图保持机头、机翼和尾部轮廓，再依据 `src/ui/aircraft-cabin-layouts.json` 的机舱区域及玩家客货分配，以 CSS 绘制舱壁、窗、地板、座椅和货盘。人物与货物按 `src/core` 快照投影，装卸只通过核心命令。客货并存时在同层前后分区；超出单页显示量通过分页展示，不拉伸机体或伪造容量。

外观模式隐藏程序化机舱及内部交互，切回时保留页码与订单身份。布局和美术修订号只影响显示，不参与存档或收益。`npm run art:verify` 校验各机型完整外观源文件、运行文件、画布、透明四角及一致性；浏览器检查横屏缩放、装卸、切换、离线解码和订单不重复。
