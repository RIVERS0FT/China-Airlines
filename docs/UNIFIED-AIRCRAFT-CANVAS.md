# 客货舱剖面图与外观图绘制规则

## 成品

每架当前飞机必须直接交付两张 1536×590 透明 RGBA 图：一张客货舱局部剖面图，一张完整封闭外观图。两张图保持同一原型、左向姿态、视角、可见宽度、基线、涂装和光照。

剖面只移除可装载舱段的近侧蒙皮。驾驶舱、发动机、机翼、起落架、非载荷腹部、尾锥和尾翼保持外观；禁止画成开门、掀板、全机骨架或透明结构图。外观图必须直接绘制完整机体，不能依靠运行时蒙皮遮罩合成。

## 容量与动态内容

底图不得预绘乘客、货物、座椅数量标签、金额、选中框或按钮。动态座椅、货盘、人物和货物由 UI 按机型容量及订单状态摆放。基础锚点数必须与目录容量一致；扩舱使用分页，不通过缩放底图伪造空间。

SkyCourier、ATR 72 和 A321 使用单主层；客货混合型在同层前后分区。747 只表现现实存在的短上层结构；DA40 只打开紧凑座舱。现实原型只用于通用结构和相对定位，不能复制现实品牌视觉资产。

## 接入与验证

当前配置通过 `pair.cutaway` 和 `pair.exterior` 直接引用双图。运行时切换整张图，并在外观模式隐藏内部交互。美术 revision 仅用于资源缓存与追踪，不参与经营存档。

自动检查包括尺寸、RGBA、透明四角、可见宽度、底部基线、双图匹配、容量布局和运行文件存在。浏览器检查切换时无跳动、机头机尾完整、内部对象不穿出、各种缩放和横屏尺寸可操作。美术更新不能修改核心容量、订单、收支或结算。
