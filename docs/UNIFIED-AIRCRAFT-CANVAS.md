# 客货舱剖面图与外观图绘制规则（2026-09-16）

本规则替换“完整剖面底图 + 近侧蒙皮图层 + 运行时合成外观”的旧绘制方式。每架飞机直接交付同一飞机的两张完整图片：一张仅展示客货舱段的剖面图、一张完整外观图。剖面不是开门或打开机舱，也不是整架飞机的结构剖视；只能沿纵向剖切可用客舱/货舱的近侧蒙皮，其他机体结构保持封闭外观。两张图独立显示，外观图不是遮罩，不能由剖面图和近侧蒙皮拼合，也不能另画成不同角度或不同比例的第二架机型。

当前v7资源位于 `art/aircraft-pair-v7/`，覆盖全部14架现役飞机。所有资源分别参考目录声明的现实原型，只研究通用机体、甲板和用途结构；统一使用原创蓝白金涂装，不含品牌标志、注册号、现实涂装或技术图纸。

## 成品与母版

每架飞机交付以下文件，均为真正透明的 RGBA PNG：

- `aircraft-{id}-cutaway-{revision}.png`：1536×590，完整左向飞机，只剖开客货舱段。
- `aircraft-{id}-exterior-{revision}.png`：1536×590，同一架飞机的完整左向外观。
- 生成器原图、完整提示词、参考边界和容量声明保存在对应 `art/` 目录；原图不是运行资源。

v7使用1536×1024上下双图纯绿母版。两架必须完全分离，分别完整落在自己的区域内，再经可复现绿底抠除、分离、独立尺度校正、统一1430像素可见宽度和560像素基线后导出运行图。处理后每张图只保留一架完整飞机；跨过分隔区的另一架残片、孤立噪点或背景碎片必须使验收失败或在可复现处理步骤中清除。

## 两图一致性

- 两图必须是同一机型、同一左向侧视角：机头、螺旋桨或发动机、座舱盖、机翼、起落架、尾翼与机身比例一致。
- 两图使用相同可见宽度、底部基线、轮廓粗细、蓝白金涂装、材质、光源和阴影方向。透明留白可以有少量差异，飞机不能裁边。
- 剖面图保留完整飞机外轮廓，只移除客货舱段的近侧蒙皮并显示该段断面边缘；驾驶舱与机头、发动机、机翼、起落架、客货舱以外的腹部、尾锥和尾翼必须保持完整外观。不得画出发动机、机翼、起落架或尾部内部结构。
- 剖开区域不得表现为舱门打开、矩形货舱门、铰接侧板、拆下的蒙皮或悬浮外壳。外观图不能透出乘客、座位或货物；驾驶舱不能被误画成额外客位。

## 容量与动态内容

- 剖面内部按目录基础载客、载货量画出恰好对应数量的客位/货位分区；0容量的舱室完全不画。1客0货样稿只允许一个空客位，不得出现货舱。
- 美术源保持空舱：不预画座椅、托盘、人物、货物、行李、金额、城市、标签或空位文字。家具、真实订单、金额和无障碍说明由UI读取核心快照后动态投影。
- 改装增加的真实容量继续分页，不能拉伸底图、复制装饰人物或制造虚假载荷。绘制分区是表现锚点，经营容量仍由 `src/core` 决定。
- 客货型必须遵循现实原型的甲板结构：SkyCourier、ATR 72和A321在同一主层前后分区；747只允许现实存在的前部短上层甲板；DA40只展示紧凑座舱。不得为了排版虚构第二层、延长上层甲板或另画第二套舱壁。

## 原创与方向

- 统一头朝左；地图3D飞机继续按航迹方向旋转，不受本规则改变。
- 现实机型、博物馆或厂商资料只能用于通用结构研究，不下载或接入其图片、商标、涂装、注册号和线稿。
- 禁止文字、水印、棋盘格、黑底、外发光和背景；四角alpha必须为0。主体边缘保留抗锯齿，完全透明像素的RGB清零。

## 兼容与接入边界

现役14架v7资源在配置中统一使用 `pair.cutaway` 与 `pair.exterior`，构建不创建 `near` 蒙皮图。历史 `sourceAtlas/nearBounds` 分支只保留对旧资源的工具兼容，不再由现役目录引用。UI对全部机型统一在客货舱剖面图与完整外观图之间切换，并在外观模式下隐藏但不卸载内部交互。

运行资源统一为 `aircraft-{id}-cutaway-{revision}.png` 与 `aircraft-{id}-exterior-{revision}.png`；历史近侧层只作为v5构建输入和像素回归，不再进入运行时DOM。

## 验收

- 自动检查14架母版尺寸、绿底四角、目录覆盖、容量声明、导出双图1536×590、透明四角、非空主体、左右留白、可见宽度差不超过2像素及底部基线差不超过1像素。
- 人工检查同机型轮廓、视角、涂装、光照、朝向和客货舱分区，并确认剖面没有侵入驾驶舱、动力、机翼、起落架或尾部。1客0货只提供一个动态客位且不提供货位。
- 接入运行时后再执行类型检查、核心单元测试、生产构建和Playwright，并覆盖桌面横屏、手机横屏、竖屏提示、外观/剖面切换、装卸、刷新、导入导出和离线启动。未接入的样稿不冒充上述流程已通过。

## v7 全机队接入（2026-09-16）

- `node scripts/prepare-aircraft-pairs-v7.mjs` 从14张保留的imagegen纯绿母版稳定导出28张1536×590 RGBA运行候选图；可见宽度统一为1430，底部基线560，透明四角通过。
- `prepare-aircraft-art.mjs` 在正常开发、测试和构建前先重建v7双图，14架全部走 `direct-pair`，不生成近侧蒙皮。
- 类型检查、单元测试、生产构建和Playwright的实际结果以本次提交与部署回执为准，不用历史v5/v6记录冒充通过。
