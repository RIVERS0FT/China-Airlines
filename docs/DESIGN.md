# 中华航空 · 当前设计

## 页面架构统一（2026-09-16）

页面结构以 [UI-ARCHITECTURE.md](UI-ARCHITECTURE.md) 为准。本增量明确替换原先机场目录、机队管理、飞机商店、经营中心使用全屏大弹窗的呈现方式：它们现在与公司组织一样属于一级工作页，共用全局骨架和底部导航；任务、设置、帮助和机场详情继续为临时模态浮层。

原设计全文原样保存在 [ARCHIVE-DESIGN-2026-09-16.md](ARCHIVE-DESIGN-2026-09-16.md)。除本次明确替换的 UI 容器与页面导航条款外，其中全部经营、存档、资源、美术、迁移、离线和交付规则继续有效；该档案内部仍按从新到旧的增量优先级解释。不是重置游戏设计，也不删除历史规范。

## 不变边界

- 场景式航空运输经营，不改为通用后台；地图、机场剖面、组织树保留各自表现。
- `src/core` 仍是经营状态唯一写入者。导航、页签、滚动和弹窗不得写入或结算经营数据。
- 游戏存档9、IndexedDB结构1、所有核心命令、经营数值、真实客货、在途收益与旧存档拒绝规则不变。
- [DISPLAY-SCALING.md](DISPLAY-SCALING.md) 的同有效比例、同 UI 缩放使用同逻辑布局保持；安全区由物理外层统一处理。
- [MAP-BROWSE-CHROME.md](MAP-BROWSE-CHROME.md) 的浮动导航、空白穿透和实际控件标签避让保持；不恢复工具行或缩放按钮。
- [AIRCRAFT-CABIN.md](AIRCRAFT-CABIN.md) 与 [UNIFIED-AIRCRAFT-CANVAS.md](UNIFIED-AIRCRAFT-CANVAS.md) 的真实机内装载、统一画布和新双视图规则保持，不添加独立客货卡片或第二内部视图。
- 单语言标题、机场代码隐藏、顶部点券只读、装卸静默反馈、地图3D飞机与离线缓存保持。

## 验收与交付

类型检查、核心与持久化测试、根/子路径生产构建、零重试 Playwright 流程均需通过。新增工作页可达性、导航位置、主滚动区域、弹窗焦点恢复、缩放和页面返回状态的验收。不得用删掉业务断言来适配新的页面结构。

在功能分支开发，通过 PR squash 合并；同步检查并行主分支变化。沿用既有 Pages 自动部署，不生成源码或静态 ZIP；没有成功部署回执不得宣称上线。未执行的检查与实际设备验证必须如实标注。
