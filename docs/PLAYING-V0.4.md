# v0.4 人员、售机和起航引导

在机队管理中选择飞机，向下滚动可见“随航调度员”和“机队更新”。首架及旧存档飞机保留免费调度员；新购买飞机需一次支付12000币雇用，无周期工资。选择任一已解锁且该飞机可达的机场作为值勤目的地即可启动值勤，不需要预先开通航线：自动从当前机场真实订单中取直达客货，有单起飞，无单等补充。停止值勤不取消在途航班。周转结束且无自动运输/计划时可解聘，不退雇用费。

出售前先停止自动运输、取消后续计划、等待落地和周转，再卸空客货。不能出售唯一飞机。残值为基础价50%加改装投入25%，界面先显示残值再二次确认。取消确认不改进度。出售释放占用机位，不减少扩建容量；已达成机队任务不回退。出售收益不计入运输收入。

新局可点击“开始起航引导”，或从“操作帮助→开始分步引导”进入。依提示使用真实按钮完成装载、进入地图、按点击顺序选择已解锁城市、起飞、到达和首航领奖。没有“开通航线”教学步骤；城市解锁后即可直接飞往。引导仅定位操作，不代玩或额外发钱。可以跳过，刷新后按存档恢复。帮助可重新打开；已完成首航的存档重新打开会定位到已有进度，不重置游戏。

地图没有单独的“单段/多段”模式按钮。当前机场为路线起点，依次点击城市形成最多5段路线；自动往返只在路线中恰好有一个目的城市时可选。撤销末段或清空路线只改临时草稿，不扣费、不改存档。

升级前建议导出旧文件；v1/v2/v3导入升级为v4并保留旧收入、旧routes记录和旧机队免费自动权限。旧routes只是兼容/运营历史，不再作为手动飞行前置条件。v4不能交给旧版读取。

验收须分别记录核心、完整浏览器、模拟横屏和真实设备状态。没有部署成功回执与可访问网址时，不能把静态包称为已上线网站。
