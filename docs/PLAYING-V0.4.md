# v0.4 人员、售机和起航引导

在机队管理中选择飞机，向下滚动可见“随航调度员”和“机队更新”。首架及旧存档飞机保留免费调度员；新购买飞机需一次支付12000币雇用，无周期工资。开通可达航线后，选择值勤目的地并启动值勤：自动从当前机场真实订单中取直达客货，有单起飞，无单等补充。停止值勤不取消在途航班。周转结束且无自动运输/计划时可解聘，不退雇用费。

出售前先停止自动运输、取消后续计划、等待落地和周转，再卸空客货。不能出售唯一飞机。残值为基础价50%加改装投入25%，界面先显示残值再二次确认。取消确认不改进度。出售释放占用机位，不减少扩建容量；已达成机队任务不回退。出售收益不计入运输收入。

新局可点击“开始起航引导”，或从“操作帮助→开始分步引导”进入。依提示使用真实按钮完成装载、开航线、起飞、到达和首航领奖。引导仅定位操作，不代玩或额外发钱。可以跳过，刷新后按存档恢复。帮助可重新打开；已完成首航的存档重新打开会定位到已有进度，不重置游戏。

升级前建议导出旧文件；v1/v2/v3导入升级为v4并保留旧收入，旧机队保留免费自动权限。v4不能交给旧版读取。

验收须分别记录核心、完整浏览器、模拟横屏和真实设备状态。没有部署成功回执与可访问网址时，不能把静态包称为已上线网站。
