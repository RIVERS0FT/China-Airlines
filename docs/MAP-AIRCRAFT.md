# 地图航线与2D飞机

浏览地图与制定航线共用贴球面的航线和统一2D俯视飞机图片。航线、飞机、机场和航程圈沿用同一正射球面相机；机场场景、机库、商店与经营规则保持各自职责。

## 路线、图片与朝向

- 航线沿最短大圆路径在球面上插值，不添加抛物线高度或径向展示间隙。路线在地平线裁切，跨日期变更线不绕远；同点、极点和对跖点使用稳定退化处理。
- 所有机型统一使用 `public/art/map-aircraft-topdown-v1.png` 原创透明2D俯视图，原图机头朝上，正面基准保持原始宽高比、高度44逻辑像素。该标记只表达地图中的飞行位置与方向；机场、机库和商店继续使用各机型完整外观图。
- 飞机纹理首次加载时启用自动mipmap及线性过滤，让1254像素原图缩小到44逻辑像素并倾斜、压缩时仍保持平滑轮廓。静态纹理的mipmap只在GPU上传时生成，不在飞行动画中逐帧重建；透明边缘沿用原图alpha。
- PixiJS 在地图原画布内绘制飞机，不创建独立3D画布。地图渲染不依赖 Three.js、GLB文件、外部纹理、解码器或在线模型服务。
- 只有存在真实 `flight` 的飞机显示飞行标记。停驻、待命或已结束的航班不保留空中飞机；“隐藏其他飞机”只保留当前飞机的在途标记，不修改经营状态。
- 飞机中心与当前航段的大圆位置一致，以已锁定出发和到达时间计算进度。飞机图片贴在该位置的球面切平面：将飞机右向和负前向两个单位切向量经同一相机正射投影，构成2D仿射矩阵 `transform { a, b, c, d }` 的两列；原图前向 `(0, -1)` 对齐航线前向。该变换同时表达转向、倾斜、压缩和剪切，取代仅在屏幕平面旋转的朝向处理。
- 正面保持44逻辑像素高度基准；靠近球体侧面时，图片随切平面投影自然径向缩短，投影面积与正面基准之比等于锚点的可见深度。地平线处自然压成线，不设置最小压缩下限。变换不镜像，不给飞机中心增加高度，也不新增3D飞机资产。
- 背面锚点直接隐藏，不参与命中。地图拖动、触摸、缩放、键盘与机场选点仍由同一画布处理，不增加覆盖输入的飞机图层。

## 生命周期、离线与状态边界

- 静止地图按需重绘；相机、相关快照、语言或选路变化才触发更新。可见飞行使用现有私有 ticker，动画上限30 fps；全部在途飞机位于背面时不持续重绘静态球面。
- 减少动态效果开启时关闭帧间位置插值，按真实快照更新。动画仅读取已锁定航班，不推进到达、能量或收益结算，`src/core` 仍是唯一经营状态写入者。
- 所有飞机共享俯视图片纹理；页面离开时清理地图画布、精灵、ticker、观察器和事件监听，不累积独立飞机画布。图片加载失败不得阻止浏览、选路或发航；WebGL不可用时保留原生机场列表回退。
- 俯视图片随 PWA 预缓存，使用相对资源地址跟随主站分配的部署位置；不交付独立地图飞机模型。美术来源及尺寸见 [当前美术资源](ART-ASSETS.md)。
- 当前存档仍为 `version: 18`，IndexedDB结构版本为2。地图视觉替换不新增经营字段，不改变路线成本、可飞性或保存格式。

## 验收范围

单项修改完成类型检查、对应路径构建及受影响的地图定向测试；推送时执行仓库完整测试，遵循 [测试约定](TESTING.md)。地图验收检查贴球面航线与飞机位置一致、统一俯视图片加载和非空像素、切平面变换及机头朝向、正面44逻辑像素基准、侧面压缩剪切且不镜像、面积倍率等于可见深度、地平线退化、无航班时无飞行标记、背面隐藏、隐藏其他飞机、静止按需重绘与飞行动画上限、桌面和两档手机横屏、触控与选点、刷新恢复、离线启动、WebGL回退、重复进出及减少动态效果。检查定义不等于通过结果，实际执行结果记录于测试文档；真实手机GPU、Safari和Firefox性能需单独实测。
