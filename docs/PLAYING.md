# 游玩指南

## 装载与运输

机场候运区中的每张卡代表一笔真实订单。点击旅客或货物装机，也可按目的地批量装载；机上对象仍是同一订单，点击可卸回当前机场。飞机客位和货位分别计算，专业货物还需要对应货舱。

订单只在最终目的地结算一次。中转时可卸下并换机，但不会提前付款。地图报价只预览，不扣费、不移动飞机、不生成订单；成功起飞才锁定航段时间、成本和可交付收入。

## 制定路线

从当前飞机或机场进入“制定路线”，按顺序点击已开放城市组成最多 5 段的本次计划。顶部显示目的地、预计时间、净利润和成本，明细显示各段费用、交付与能量。城市解锁后可直接前往，不另收航线建设费。

起飞仍需满足机型航程、两端机场等级、资金、能量、周转和人员状态。多段途中如果后续资金或能量不足，飞机停在实际机场，保留机上未交付订单并结束剩余计划。

## 自动值勤、能量与人员

自动值勤需要有效飞行员，只装载当前机场真实直达供给；没有订单时等待，不空飞刷收益。停止值勤不会取消已在途航班。

能量按航段飞行时长预留，空飞同样消耗。机库可安排或取消补能；补能中的飞机不能装卸、起飞、改装、调岗或出售。地勤能力只缩短之后开始的补能，不改变已锁定截止时间。

公司组织页用于录用、分配、培训、晋升和续约。经理提供有限培训折扣，地勤提高负责机场的补能效率；没有经理或地勤仍可手动经营。

## 机场、机队与保存

机场目录可搜索和筛选，详情显示候运目的地、停靠飞机和当前航班。浏览空机场不会把异地飞机移来；购机可交付当前机场。机队页用于定位飞机、查看状态和进入机库。

设置中可以导出当前存档。导入只接受严格有效的当前 `version: 10` 文件；失败不会覆盖现有主存档或备份。刷新会按墙钟推进最多 8 小时离线事件；主动导入不领取文件存放期间的离线收益。

游戏是 PWA，可在至少成功联网打开一次后使用缓存离线启动。语言与 UI 缩放单独保存在浏览器中，不随经营存档导入、导出或重新开始而改变。
