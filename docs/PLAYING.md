# v0.2 上手：从装载开始

主页是机场场景，不再是管理后台。开局18万游戏币、北京/上海机场和一架云雀70。

1. 在下方候机大厅点击旅客/货物卡片装载，或选择城市后点击「同目的地装载」。每张卡是一整单，不能超出机型座位/吨位。
2. 点击飞机或「机上客货」查看清单；在地面点击清单卡片卸下。已接受订单不会过期，卸下不是取消或交付。
3. 点击右下「选择航线起飞」，地图选择目的地，首次需要开通航线。检查耗时、成本、本段交付金额及净收益，再确认起飞。
4. 飞行中不能装卸；可用两侧箭头或机队管理切换到其他飞机。到达后交付最终目的地订单，其他订单仍留在机上，8秒周转后继续操作。
5. 中转示例：北京发往上海的旅客先飞武汉，在武汉卸下，让另一架飞机装载后飞上海。只有上海交付付款，北京→武汉段不发钱。
6. 自动往返要求首航先装载且全部直达；之后从机场真实客货池按容量自动取单，无订单时等待补充。关闭自动不取消当前航班。

开通机场和升级在航线地图进行。购机时选择交付机场，飞机立即停靠该处；机场等级不足或资金不足会显示购买限制。商店只有已实现的三种虚构机型，不代表完整原版养成内容。

客源每120模拟秒补充，未接受订单360秒到期；已装过的订单长期保留。空机调机只有成本，没有收入，需二次确认。客货报酬按原始起终点锁定，中转不增加金额。

旧v0.1存档会自动迁移，旧在途航班保持锁定收益。新v2存档不能交给旧游戏读取。请在存档设置中定期导出；导入替换进度前会确认，错误文件不会覆盖。离线最多补算8小时，前提是此前已完成PWA缓存。手机使用横屏，竖屏显示旋转提示。
