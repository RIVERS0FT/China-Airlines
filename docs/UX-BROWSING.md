# 机场与机队浏览 UX

## 范围

继承 DESIGN.md 的独立发航界面：四项读数与地图布局不变，机场、路线和能量信息仍按需打开。本轮只改 UI 和浏览器测试，不修改经营核心、收益、后台航班结算、能量、存档格式、依赖或部署流程，不恢复离线统计界面。

## 机场浏览上下文

机场目录保留当前页面会话中的搜索词、开放筛选、滚动位置和刚查看的机场。进入详情再返回时恢复原卡片焦点与滚动位置；若解锁等操作导致卡片不再符合筛选，则焦点回到搜索框。关闭后重新打开也保留条件，整页刷新则恢复默认“已开放”。状态仅存于独立的内存 UI store，不写入 IndexedDB、localStorage 或游戏存档。

搜索维持原有城市、机场代码和区域匹配规则。新增结果数量、独立清空按钮和空结果“查看全部机场”恢复入口。清空后焦点留在输入框；切换条件回到列表顶部，不自动检查、解锁、装载或移动飞机。原生搜索框有内容时，Escape先清空查询；使用关闭按钮保留条件，焦点不在搜索框时Escape关闭弹窗。窄横屏让筛选与搜索并排，空间不足才换行，为机场卡片留出更多高度。结果提示只朗读筛选数量，不将每秒更新的客货数和倒计时放进 live region。

## 机队运行表

保留全部、待命、飞行中三个常用筛选；增加地面周转、地勤补能、自动值勤与计划周转的下拉筛选。搜索可以叠加状态，匹配飞机编号、机型、当前航班编号、起讫城市或机场代码，忽略大小写与首尾空格。维持原机队顺序，不随倒计时排序，以免正在操作的行跳动。无结果可一键重置。非待命地面飞机的入口改称“查看飞机状态”，避免暗示当前可立即装载。

## 弹窗与横屏

机场与机队浏览的搜索、筛选、清空控件至少44px高，主弹窗关闭按钮至少44×44px，标题栏滚动时仍可见。两种本地弹窗限制滚动链；浏览界面支持减少动态效果偏好。地图弹窗只有按下与点击都位于边界外才关闭，从内部拖到外面不关闭。Escape和关闭按钮继续工作，关闭恢复入口焦点，不撤销路线草稿或重建地图。

## 验证边界

新增 e2e/browse-ux.spec.ts 覆盖1440×900、844×390和667×375、搜索/筛选保留、焦点、滚动恢复、空结果、机队状态与搜索组合、弹窗外部点击/拖动/ESC、地图节点和草稿保留、资金不变与无横向溢出。使用既有CI执行类型检查、全量单元测试、根路径及Pages子路径构建与零重试浏览器测试，截图写入artifacts目录。新增用例不替代既有存档、能量、离线启动与发航安全回归。实机触屏和非Chromium浏览器仍需单独验收。
