# 地图统一 3D 飞机

用户于2026-09-15选定 A 款 Low Poly Airliner，并提供原始 GLB。首版仅替换浏览地图与制定路线中的飞机，不扩展到机场场景、机库或商店，不代表所有游戏机型的真实外形。

## 资源与渲染

- 作者：Mauro3D，来源 https://sketchfab.com/3d-models/low-poly-airliner-f06d488f08764e3ca26f2917d4053c69 。CC BY 4.0，完整署名和修改说明在 `public/models/ATTRIBUTION.txt`，中英文帮助可访问。
- `public/models/low-poly-airliner.glb` 保留原文件和内嵌许可，257,356字节，无外部纹理或解码器。Three.js / @types/three 固定0.186.0；库随本地构建交付，不从 CDN 加载。
- Three.js 加载后隐藏 `Cylinder001`、`Cylinder002`、`Cylinder003` 三组起落架；两个机体材质共2,284个三角面。模型本身 +Z 为机头、+Y 为顶部；居中并按机身长度归一化，所有机型统一52逻辑像素。当前飞机浅暖白色，其他飞机保留原色。
- 保留 PixiJS 正射球面、城市、标签、航线与背景。独立透明3D画布使用相同圆心、半径、缩放和相机旋转，正射投影与现有航线坐标一致。画布不接收输入、不新增焦点；原 PixiJS 画布继续处理拖动、触摸、缩放与键盘。
- 飞机机头沿当前抛物线航迹的三维切线；顶部由当地球面法线确定，正交化消除镜像或倒置。包含起终点、经线跨越、同点及极区退化处理。停驻飞机沿用机场上方20像素的标记偏移。网格中心另加5像素径向展示间隙，避免端点机腹与球面重合；路线和命中锚点不改变。
- 背面锚点直接隐藏。透明层内增加只写深度的球体，裁切机体与球面的遮挡；网格内部使用正常深度测试。两个材质分别实例化，同机队所有飞机共享几何和材质。

## 生命周期、离线与回退

- 由现有最高30fps的私有 ticker 驱动，不增加自己的动画循环。静止或全部飞机位于背面时，只有相机和业务快照发生相关变化才绘制。减少动态效果开启时关闭帧间位置插值，按真实快照更新。
- 模型异步加载期间保留原 PNG。文件损坏、缺失或3D初始化失败时继续使用 PNG；不能阻止机场浏览、选路或发航。完整 WebGL 不可用时保留原城市选择器回退。
- 页面离开时中止加载，销毁画布、实例、几何、材质、纹理和 WebGL 上下文；异步加载晚到时立即释放。重新进入不累积画布与监听器。
- 模型、库代码及许可随 PWA 预缓存，支持根路径与 `/China-Airlines/` 子路径。不请求在线模型或登录服务。
- `src/core` 仍是唯一经营状态写入者。模型只能读取快照；动画不参与到达、能量或收益结算。包版本保持0.8.0、存档9、IndexedDB1。

类型检查、全部核心与存储单元测试、生产构建、根/子路径 Playwright。新增验证实际 A 款模型的来源、无外部依赖、隐藏起落架后的面数、资源释放、三维正交姿态和投影一致；浏览器检查实际模型加载与非空像素、桌面和两档手机横屏、触控穿透、球体正背面、隐藏其他飞机、刷新及离线启动、模型失败回退、重复进出、减少动态效果。保留竖屏提示与导入导出既有验收。检查定义不等于通过结果，最终以实际命令回执为准；真实手机GPU、Safari和Firefox性能未据此验收。
