# 本地化架构

本地化属于 UI 展示层，不进入 `src/core` 的经营状态、命令、存档键或数据库结构。核心保存稳定机场、机型和物资 ID；语言偏好单独保存在浏览器 `china-airlines:locale:v1`，导入、恢复备份和重新开始不得改写。

`src/i18n/locales/` 保存 `zh-CN` 与 `en-US` 的语义消息，`registry.ts` 管理语言清单，`catalog.ts` 将稳定实体 ID 映射为本地名称。正式新界面必须使用语义 key，并由 TypeScript 保证各语言键集合完整。

部分当前界面仍通过中文源文本翻译表调用 `ui()`。这只是当前本地化实现方式，不读取或迁移旧存档，也不能修改经营状态；新增模块优先使用语义 key。核心中文日志通过只读文本投影翻译，未知文本原样显示。

切换语言必须立即更新 `html.lang`、标题、数字、时间、机场和机型名称，同时保持地图镜头、路线草稿、弹窗焦点、组织树选择和经营状态。未知 locale 回退到 `zh-CN`。

当前存档只支持 `version: 10`，IndexedDB 结构版本为 1。语言切换不得放宽严格校验，不得使用翻译后的实体名作为命令参数、搜索身份或存档键，也不改变 PWA 缓存规则。
