# 启动、默认地图、航行动画与本地化（2026-09-14）

## 入口与导航

首次打开当前浏览器标签页时显示独立游戏开始界面，使用原创本地飞机航行素材、分层天空和云层作为场景。存档在后台完成严格读取；读取完成前“进入游戏”禁用，存档需要恢复时只能先进入存档设置。进入游戏后默认打开只读地图浏览页。

普通底部入口固定为：地图、机场装载、机场目录、机队管理、飞机商店、公司组织、经营中心。公司组织是独立页面，不再位于经营中心页签。地图是最左侧且在浏览页保持选中；浏览地图保留底部导航，可直接切换经营页面。“制定路线”只在机场页作为独立高优先级入口，路线规划页继续隐藏全局导航，防止把浏览和派航混为同一状态。标签页内刷新保留已经进入游戏及当前地图/机场页，关闭后重新打开仍显示开始界面；这些会话偏好不进入游戏存档。

此条替换 `CAREER-NAVIGATION.md` 和 `TASKS-FLEET-LOADING.md` 中“机场装载位于最左”和“独立地图隐藏底部导航”的旧约定，不修改核心经营、路线规划或结算规则。

## 航行动画

开始界面和实际在途机场场景共用纯装饰 `FlightSky`。近云、远云使用不同速度横向移动，飞机使用小幅升沉和俯仰；实际在途场景使用已有 `aircraft-flight-v1.png`。`prefers-reduced-motion: reduce` 时停止飞机和云层动画。

动画只读取 `plane.flight` 决定是否显示，不推进模拟时间、不触发抵达、不扣能量、不结算收入。到达与离线收益仍只由 `src/core` 的时间事件结算，地图和动画回调均不得写入经营状态。

## 本地化

首批支持 `zh-CN` 与 `en-US`，默认中文。开始界面、地图、主导航、机场装载、机场/航班目录、路线规划、任务与存档设置使用同一 React 本地化上下文；机场、机型、区域采用稳定 ID 到本地名称的目录。语言可在开始界面、地图页头和设置内切换，立即更新 `html.lang`、页面标题、数字/时间格式，偏好独立保存于 `china-airlines:locale:v1`，不写入或改写经营存档。

核心继续保存稳定 ID 和既有中文经营日志/错误，不依赖 React 或本地化模块。UI 对旧日志和错误做只读翻译，因此本增量沿用公司组织功能定义的存档 v8、不放宽 v1—v7 的冻结校验。新增语言时扩展语义消息表、机场/机型目录及过渡文案表；不得在核心写入展示语言，也不得用翻译后的机场名作为搜索、命令或存档键。英文机场搜索同时匹配英文城市、区域、IATA 代码和原中文字段。

## 验收

浏览器流程覆盖：新标签开始界面及键盘焦点、飞机航行视觉、进入后默认地图、地图按钮最左且选中、英文切换和英文机场搜索、刷新会话恢复、真实在途场景动画，以及减少动态效果。既有经营流程从机场工作区执行，继续验证桌面、844×390、667×375、竖屏提示、导入/导出、刷新恢复和离线启动。
