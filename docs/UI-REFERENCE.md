## 装载页

保留顶部资源、机场牌、大飞机、两侧换机、下方客货和右下角起飞入口。客货区用连续候运地面、不同旅客组/行李和货运车表达候运；标签仍然是真正的原生按钮，不能仅展示插图代替装载。

队列左右按钮每次滚动约一屏、保留一项上下文。支持触摸横向滚动和聚焦列表后的左右/Home/End；只有列表自身获得键盘焦点才处理这些按键，不拦截卡片或选择器操作。列表无溢出时禁用翻页。切换飞机、机场、客货分类或机上/候运区时回到队列开头；模拟时间推进和单次装载不主动重置滚动。

卡片显示最终目的地、人数/吨位、锁定报酬与装卸状态。飞行、周转、自动值勤、剩余路线、类型不兼容、客舱/货舱不足、候运区满必须明确说明，禁止显示“点击卸下”但实际不可卸。界面解释只读，核心仍然重新验证每条命令。

短横屏使用同一机体的紧凑侧视：缩短垂尾并去除SVG上下留白，不把整架飞机等比缩成小图标；保留翼面、起落架、舱位和清单入口。桌面继续完整侧视，不改变机型或经营数据。

桌面候运区保持完整竖向卡；844×390与667×375采用人物在左、数量/报酬在右的紧凑卡，关键操作/禁止说明至少11px，不以隐藏文字换取高度。引导期间检查状态文字完整位于卡片内。保持竖屏提示，不依赖锁屏。

## 航网页

路线编辑只有一套交互，不显示「单段派航 / 多段计划」切换。飞机真实停靠城市固定为起点；玩家依次点击地图城市，每次有效点击把该城市追加到草稿，点击顺序就是飞行顺序。第一座城市自然形成单段，继续点击自然形成多段；最多5段。相邻不能是同一城市，允许在经过其他城市后再次回访起点或旧城市。撤销只删除末站，清空只清除草稿。

已解锁城市不再需要单独建设或付费开通城市之间的航线。地图只验证机场是否解锁、两端机场等级与当前机型航程；实线表示满足这些条件，虚线表示当前航段不可飞。方向箭头、起点0和访问序号说明顺序，返回同一机场时合并显示访问序号。预览不扣费；每段运营成本只在该段实际起飞时由核心结算。

地图点击是主要路线输入。下方城市下拉保留为键盘和无障碍备用入口，但必须调用同一顺序编辑函数，不能成为另一套「目的地模式」。点击未解锁城市只改变浏览选择并提供城市解锁操作；解锁成功后可立即加入当前草稿。飞行中地图保持只读浏览，不出现确认起飞控件，也不得更改锁定航班账目。

预览调用核心 `legQuote` / `planQuote` 读取当前航程、机场等级、用时、运营成本和交付规则，不复制飞行公式。路线草稿、撤销、清空、地图浏览均不得派航、付款或改存档。自动往返只在单站路线下可选，并继续要求随航调度员和全部机上订单直达。

地图保留费用明细、可访问路线文字和WebGL降级入口。历史 `routes` 数据只可用于已飞航迹/自动值勤技术索引，不得再渲染为「已购买航线」资产。所有绘制仅为读快照；与飞机真实位置或收益结算无关。城市字号/相机仍遵循MAP-LAYOUT.md。

## 本轮验收

保留全部未冲突v0.4用例，并替换旧航线模式断言：页面不存在「单段派航」「多段计划」「开通航线」「开通计划航线」；按武汉→北京→上海选择得到同序3段草稿；撤销末站/清空路线实时更新；回访与无效段仍正确标记；路线预览零经营写入；已解锁城市可直接确认起飞。继续覆盖订单禁用原因、桌面/横屏翻页与筛选复位、空列表边界、在途不可卸提示、引导标签几何边界及草稿实际渲染标记。输出1440×900、844×390、667×375截图。
