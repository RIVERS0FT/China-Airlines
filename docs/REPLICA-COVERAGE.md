# 复刻覆盖清单：证据、实现与缺口

这不是完成百分比，也不是原作全功能已经穷尽的清单。必须分别检查「原作有无此功能」「航空版是否可操作」「规则是否等价」「界面是否逐页核对」。测试通过只能证明当前实现满足自己的断言。

## 操作流程覆盖

| 编号 | 对照对象/来源 | 航空版实现位置 | 当前可操作范围 | 差异或下一项验收 |
|---|---|---|---|---|
| F01 | 站点浏览、在站点操作载具 / R1 | AirportDirectory、AirportDetails、App | 机场浏览及无机停机坪 | 目录/详情的原版具体布局待核；到离港表为航空化呈现 |
| F02 | 运输旅客、货物 / R1、R2 | core/game、OrderBoard | 独立订单、逐单/同目的地装载、卸载 | 订单规模、刷新周期、报酬未与原版等价校准 |
| F03 | 载具容量/最大里程及站点等级 / R1 | catalog、legQuote | 独立客货容量、改装后航程、两端等级 | 航空机型与机场等级成长采用本作参数 |
| F04 | 地图按站点顺序规划运输线路 / R1及用户提供的原作操作对照 | Network、PlanControls、MapView | 当前机场为起点，依次点击已解锁城市形成1至5段；可撤销/清空并直接起飞 | 五段上限和途中不补装仍是本作规则；不再有单段/多段模式按钮或付费开通航线 |
| F05 | 客货中转 / 待固定客户端核验 | core/game、OrderBoard | 同机经停、机场卸货后换机，最终目的地一次付款 | 原版完整中转费用、容量和奖励待核实 |
| F06 | 车型分类 / R1 | catalog、Shop | 纯客/纯货/混合各3款 | 原作内容数量未覆盖，9款为原创机型 |
| F07 | 改造性能、升级容量 / R1、R2 | aircraftSpecs、Hangar | 四项各三级，统一有效参数 | 航空化舱位不等于火车加挂车厢；费用和上限待校准 |
| F08 | 车库扩张 / R1 | expand-hangar、Hangar | 4至16机位 | 规模和费用为本作配置 |
| F09 | 司机自动装载 / R2 | AircraftService、start-duty | 调度员、已解锁可达城市的直达自动往返、无供给等待 | 一次性雇用规则为本作配置；独立人物/转岗未实现 |
| F10 | 载具出售 / 待客户端核验 | resaleValue、sell-plane | 安全售机与历史机队任务 | 不等于封存/退役，原作出售路径与残值待核实 |
| F11 | 退役/封存 / R1 | 尚无 | 未实现 | 不能用售机标作已完成；需先确定封存机位和恢复规则 |
| F12 | 零件、拆解、组装 / R1 | 尚无 | 未实现 | 需定库存、组装费、交付地点、重复收益防护 |
| F13 | 电量/能量消耗及恢复 / R1 | core/energy、EnergyService | 部分：每分钟1点、240点示例档、起飞预留/不足停止/手动补能 | 全原版容量与恢复规则未核；120秒免费补满为明确暂定航空化适配，见ENERGY.md |
| F14 | 关闭站点及客流分配 / R1 | 尚无关闭命令 | 仅有解锁与升级 | 关闭前订单/在途/历史通航记录处理与任务影响待设计 |
| F15 | 更大网络/国际运输 / R1 | 仅12机场配置 | 未覆盖原作完整运输网络 | 不通过增加装饰地图标记算完成 |
| F16 | 任务、引导 / R1提及任务；步骤待核 | Tasks、Tutorial | 4项任务、6步首航引导 | 现有奖励/步骤为本作，完整任务链未对照 |
| F17 | 循环多段自动接单 / 待客户端核验 | 尚无 | 当前只支持有限计划及单线自动往返 | 未确认原版机制前不编造为原版已知功能 |
| F18 | 人员技能/养成 / 待客户端核验 | 尚无 | 仅布尔调度席 | 不是已经证实的必做原作机制，保留待核 |

## 界面覆盖与证据

| 页面/状态 | 当前实现 | 当前检验 | 仍缺什么 |
|---|---|---|---|
| 装载场景 | 大飞机、客货队列、机场牌、换机和底部操作 | scene-polish、orders及截图 | 同一原版客户端的尺寸和反馈逐页比对 |
| 航网 | 按城市点击顺序选路、草稿方向/编号、逐段费用、不可飞原因 | plan-details、fleet-plans、scene-polish | 原版地图美术和全套编辑状态的对照；历史routes只作已运营网络表现 |
| 飞行 | 飞机侧视、剩余时间、清单、切机 | game、recovery | 景物、过渡、到达反馈的精确还原 |
| 商店/机库 | 分类、购机、改装、调度员、售机 | management、fleet-plans | 原版分页/封存/零件页不齐全 |
| 机场目录/详情/空机场 | 复用真实队列与载具位置 | airports单元/E2E | 是航空化工作流补齐，尚非像素复刻 |
| 任务/教学 | 当前任务和真实状态引导 | management、tutorial-feedback | 原版完整链条和引导台词未对照 |
| 本地存档/设置 | 备份、迁移、导入导出、离线和并发防护 | storage、recovery | 属单机Web工程能力，不折算为原作玩法覆盖 |

账号、充值、广告、联盟及联网经济不进入当前单机运行依赖。它们列为「单机范围排除/待单机替代决策」，不是已复刻，也不能和封存/能量等实际玩法缺口混为一谈。

## 本轮完成定义与后续顺序

本轮将F04路线操作修订为“机场解锁后即可前往，地图点击城市的先后顺序即路线顺序”，删除玩家可见的“单段/多段”模式和航线建设费。存档中的routes保留兼容，只在真实起飞/自动值勤时记录已使用城市对；不作为手动飞行前置条件。机场浏览、客货位置、收益结算与存档版本保持既有边界。

后续优先拿到统一原版客户端的界面与规则记录，再处理F11/F12/F13/F14的关联设计和迁移。涉及能量、封存、拆装或关站时必须先列清与当前数值/存档的冲突，再修改设计、核心和测试；不静默给旧存档收费或丢弃客货。
