# 独立发航页 · 精简复刻验收

本文件替换此前“全局经营界面＋常驻城市浮动工具”的布局条款。依据用户提供的《中华铁路》发车截图及已确认方案，发航默认只保留四项读数、地图、必要路线按钮。只复刻页面层级与操作关系；使用现有原创地形和飞机，不把参考截图或其他游戏素材打包。

## 常驻布局

进入航线地图后隐藏全局资源栏、主导航和正常通知；退出后恢复。飞机位置、资金、订单、控制器、存档都不因页面切换改变。顶部连续深灰读数条仅有目的地、预计时间（飞行中为剩余时间）、净利润、成本。预计时间沿用计划总时长，包含途中周转，不误标为纯飞行时间。目的地只显示最后一站，完整路线与交付收入改为按需明细。

地图直接延伸到视口底部，不再有网络说明/能量横条、城市工具组、全局底栏或独立控制台占位。1440×900、844×390、667×375的地图高度均至少为视口85%；正文和按钮不能依靠溢出或缩成不可触控尺寸达标。控件触控区域不小于44×44。

左下只有放大/缩小，取消独立复位按钮；点击当前飞机或聚焦地图按Home定位当前飞机。其上是隐藏/显示其他飞机，不隐藏当前飞机、城市、草稿或航程提示。其右依次是路线后退（删末段）、路线撤销（清空）、取消起飞（退出）、查看路线。唯一检票起飞按钮在右下，视觉文字与可访问名称一致，继续复用核心dispatch/dispatch-plan，不增加检票经济机制。

城市标签仅显示城市和简短等级/未解锁状态，不再铺满代码或解锁价格。历史通航记录弱化，草稿线、方向、序号仍可见。范围圈围绕草稿末站提示下一段，否则围绕当前飞机停靠地；圈是游戏化提示，不取代核心航程/等级验证、不移动真实飞机。

## 按需信息与导航

点击或键盘激活顶部目的地打开原生“选择城市”对话框，原生选择器是地图无法渲染时的完整替代入口。选中开放城市追加草稿；未开放城市转入现有机场详情，保存解锁成功后返回原地图并追加，失败或取消不追加。飞行中选城市仅浏览，不改变锁定航班。城市详情入口在该窗口内，不常驻。

“查看路线”打开原生“路线详情”，包含完整路线、逐段时间/成本/交付、机上未交付订单、可用/所需能量与自动往返。自动仅在单一目的地且有调度员时可设置，实际装载限制仍在确认起飞处解释。启用后关闭窗口，起飞按钮附近保留自动往返标识。窗口不重新挂载地图；关闭或Escape恢复入口焦点，草稿和相机不重置。

空草稿不显示无关说明，只禁用检票起飞。首次进入本次运行显示一条可关闭提示；选择城市后自动消失，后续进入不重复显示。原首航引导在机场继续，地图阶段用实际目的地/起飞入口，不保留额外常驻教学条。

阻断原因在起飞按钮附近显示一条简短文字；明细中保留完整数据。首段资金/能量不足不能起飞；总能量只够部分航段仅警告，仍按现行逐段规则处理。负利润不是禁止起飞的理由；空机或未交付确认继续保留。保存失败、存档冲突等关键告警不可被精简隐藏，保存异常保留设置入口；普通到达报告延后至返回机场呈现。

取消只丢弃草稿并回到进入前的飞机/固定机场/机上客货视角，不退已完成的机场升级/解锁，不卸货、不取消当前真实航班。飞行中用“返回航班”，不显示检票起飞或取消起飞。用户已在地图期间航班到达，可回到原视角或继续规划，账目只读实际核心状态。

## 不变范围与验收

包版本0.5.0、存档格式5不变，不变更core、runtime、persistence、PWA、依赖和已有正式CI/Pages流程。新测试包含四项读数与无常驻冗余、三个视口地图比例/触控区域/按钮不重叠、城市选择和WebGL回退、弹窗焦点与相机保留、末段航程圈、不改变草稿时隐藏飞机、空机场取消返回、实际起飞/能量不足/自动边界以及错误提示可达。

保留原有经营与存档回归目的，测试通过新的真实可见入口操作，不强制点击隐藏控件；被移入明细的信息必须打开明细后验证，不用删除断言或重试掩盖失败。最终验收需类型检查、全量单元、根/子路径构建和零重试Chromium回归，查看实际截图，核对ZIP与源码树后squash合并并验证发布。模拟视口不代表真实手机；本轮也不宣称原作全玩法/全美术复刻完成。
