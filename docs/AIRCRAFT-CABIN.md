# 飞机客货舱

机场场景在每架飞机完整外观图上显示程序化机舱。舱壁、窗、地板、座椅和货盘由布局坐标与 CSS 绘制；机舱图层只覆盖当前可装载区域，机头、机翼、发动机与尾部继续使用外观图。玩家同时分配客位与货位时在同层前后分区，不虚构第二层。

- 舱内空间按机型额定容量等分，座椅和货盘数量读取玩家当前客货分配，客位在前、货位在后，各分区宽度与所占容量成比例。未分配空间留空，不生成可装载槽位；空机身显示改装提示。现役1–10格全部同屏呈现，不再固定各占一半或在5/8格后分页。
- 窗与舱壁按容量生成；装卸只改变已配置槽位上的人物/货物占用，不增减座椅或货盘，不复制订单。
- 候运区和机舱内是同一个订单对象。装机、卸载及切换外观不复制、删除或结算订单。
- 旅客和货物的目的地与金额在对象下方居中分两行显示。
- 人物图集在候运区显示站姿，机上显示对应坐姿；货物使用类别图集。
- 外观模式隐藏程序化机舱与内部交互；切回后保留槽位及订单身份。

布局使用 1536×590 的共享坐标系，机头朝左；座椅与货盘按对应机型地板线定位。UI 只读取 `src/core` 快照并发送装卸命令，不自行修改容量、奖励或航班。当前存档为 `version: 14`，数据库结构为 1；布局没有独立迁移逻辑。

验收覆盖 10 架现役机型的独立外观图与程序化机舱、空机身、客货分区比例、满容量同屏、装卸、横屏缩放、刷新恢复和离线资源。外观全部更新为v8，旧版与初航机资源已移除。
