# 飞机客货舱

机场场景使用同一架飞机的客货舱剖面图与完整外观图。剖面只打开可用客舱或货舱段，驾驶舱、机头、发动机、机翼、起落架、尾锥和尾翼保持完整；混合型按现实甲板关系前后分区，不能为了排版虚构第二层。

## 装载与显示

- 底图提供与基础客货容量一一对应的可交互锚点；容量改装增加的槽位通过分页展示，不拉伸底图。
- 候运区和机舱内显示同一个订单对象。装机、卸载、换页或切换外观都不能复制、删除或结算订单。
- 旅客或货物的目的地与金额在对象下方居中分两行显示，不放在右侧。
- 旅客使用稳定人物图集，候运时显示站姿，机上显示对应坐姿；货物使用类别图集。
- 外观模式隐藏内部交互并显示整张封闭外观图；切回剖面后保留原页码与选中状态。

## 几何规则

剖面图与外观图统一为 1536×590、头朝左、相同机体、视角、可见宽度、基线、涂装和光照。座椅与货盘的地板接触点必须落在当前机型配置的地板线上；缩放、翻页和不同容量下不能漂浮或穿出舱体。

## 经营边界与验收

客舱 UI 只读取 `src/core` 快照并发送装卸命令，不自行修改容量、奖励或航班。当前存档为 `version: 10`，数据库结构为 1；美术布局没有独立迁移逻辑。

验收覆盖 14 架飞机双图、基础容量锚点、扩舱分页、客货混合分区、下方目的地/金额、装卸命令、飞行/补能锁定、桌面及手机横屏、UI 缩放、刷新恢复与离线资源。
