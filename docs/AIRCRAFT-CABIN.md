# 飞机客货舱

机场场景在每架飞机完整外观图上显示程序化机舱。舱壁、窗、地板、座椅和货盘由布局坐标与 CSS 绘制；机舱图层只覆盖当前可装载区域，机头、机翼、发动机与尾部继续使用外观图。混合型客货前后分区，不虚构第二层。

- 基础槽位与机型客货容量一一对应；容量改装增加的槽位通过分页展示。
- 候运区和机舱内是同一个订单对象。装机、卸载、换页及切换外观不复制、删除或结算订单。
- 旅客和货物的目的地与金额在对象下方居中分两行显示。
- 人物图集在候运区显示站姿，机上显示对应坐姿；货物使用类别图集。
- 外观模式隐藏程序化机舱与内部交互；切回后保留页码及订单身份。

布局使用 1536×590 的共享坐标系，机头朝左；座椅与货盘按对应机型地板线定位。UI 只读取 `src/core` 快照并发送装卸命令，不自行修改容量、奖励或航班。当前存档为 `version: 10`，数据库结构为 1；布局没有独立迁移逻辑。

验收覆盖 14 架独立外观图与程序化机舱、基础容量锚点、扩舱分页、混合分区、装卸、横屏缩放、刷新恢复和离线资源。
