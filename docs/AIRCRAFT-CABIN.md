# 机场装载：侧面剖视机舱（2026-09-15）

机场装载页使用原创侧面剖视机体，客舱内排列旅客与座椅，货舱内排列货箱与托盘。继承《中华铁路》车厢装载的空间操作方式，不复制其素材或代码，不宣称飞机内部结构与原作一比一复刻。

装载场景的机头、地面与舱内客货统一采用朝左的展示方向，空座椅随之转向。乘客改用原生接近正面、略偏左的新版站姿/坐姿图集；24种货物采用各自原生图集方向，二者均不再镜像。飞机和空座椅继续仅镜像美术图层。目的地、数量、价格、操作文字及翻页顺序保持正常阅读方向；不改变地图飞机按航迹定向的规则。候运客货脚下使用柔和椭圆阴影，移除白色描边椭圆底座；价格/物资名称直接悬浮，不再显示金额底板及装机/不能装载原因文字。真实禁用状态、无障碍原因及容量判断保留。移除机场牵引车、行李拖车、地勤人员和路锥装饰。

## 替换的约定

本增量替换 DESIGN.md、AIRPORT-REFERENCE.md、TASKS-FLEET-LOADING.md 中“已装机订单仍在地面原位展示”和“停靠飞机只显示容量图标”的条款。ART-ASSETS.md 中机场按实际机型显示 PNG 的规则在停靠装载场景改为通用剖视机体；实际机型名、容量仍读真实飞机。地图 3D 模型、飞行场景、机库与商店的既有美术规则保持。

## 装卸与舱内位置

- 地面仅显示当前机场待运订单，按目的地站牌分组。点单个客货或站牌，调用原有 `load` / `load-destination` 命令。
- 保存成功后，同一订单从地面移至当前飞机的客舱或货舱。旅客从站姿切换为同一人物的坐姿，卸载后恢复站姿；人物编号、服装、货物类型和订单 ID 保持。容量为0的舱不显示。没有订单时只显示空座椅/空托盘，不能生成装饰乘客或货物冒充载荷。
- 点击舱内人物/货箱，通过原有 `unload` 命令返回地面目的地分组。补能、周转、自动值勤、剩余计划、候运区满和保存中均沿用既有禁用条件。客舱满不影响可用货位，反之亦然。成功装卸继续静默，不新增弹窗。
- 地面旅客只显示悬浮价格；普通货单显示具体货名和价格两行，贸易物资保留真实物资名称。舱内客货下方以两行悬浮文字显示目的城市和实际订单金额，具体货名在悬停与可访问名称中保留，不显示卡片底色、边框或卸载提示文字。点击客货卸载保持，操作与限制保留在可访问名称及悬停说明中。金额直接读取 `order.reward`，不另外计算价格。旧聚合订单以一个带实际人数/吨数的群组显示，真实容量按 `amount` 扣除，不拆单、不改价格。
- 每舱独立分页，页内为按创建时间及订单 ID 稳定排列的已装订单，其后为空位。页面大小随逻辑宽度变化；卸载后可紧凑排列。新装入订单自动翻至包含它的一页，切换飞机或刷新从首页展示。不写入座位号、分页或额外存档字段。
- 翻页仅改变展示；支持按钮及方向键、Home、End。查看机上客货入口回到舱内首页并移动键盘焦点；卸载后焦点保留在对应舱。使用已有统一 UI 缩放。

## 候运区紧凑布局（2026-09-15）

按用户要求缩小地面客货区高度和间隔：普通逻辑布局高度由194降至144，短逻辑横屏（高度不超过600）为104，默认100%缩放占页面高度20%，150%缩放约22%。释放的高度由上方机场场景使用。单个客货占位由130/118缩至96/88，组内间距由12/6缩至6/4；同目的地仍按真实订单稳定排列，不改变装卸或滚动交互。

目的地路牌按文字自然宽度显示，普通布局宽64–160、短横屏宽56–144，长城市名自动换行，文字居中；取消固定124/100宽度。路牌与队列翻页按钮保持至少44逻辑像素高，长名称与金额不得裁切。以上尺寸继续使用统一UI缩放，不按实际设备像素分套布局。此规则取代旧机场参考文档的28%客货区及桌面维持原比例约定。

## 经营与阶段边界

`src/core` 仍是经营状态唯一写入者，容量、收益、时间事件、最多8小时离线补算、时间回拨规则均不改变。包版本0.8.0、存档9、IndexedDB结构1、依赖不变。所有素材与程序随 PWA 离线缓存。

本阶段是可操作的二维剖视示意，不提供走动登机、拖放选座、真实机型座位布局或碰撞模拟。飞行中继续显示已有航班场景和只读容量示意；到达最终目的地的订单按核心结算后消失，中转订单继续显示在机内。
