# v0.3 地图视口补充设计

本文件补充 DESIGN.md 第8节，不改变订单、资金、运输计划或存档规则。

## 城市文字和相机

地图整体缩放最低0.75：18像素城市字号显示至少13.5像素。大视口可以完整居中展示960×630的航网；尺寸不足时，默认显示聚焦当前城市的局部区域，不把全国航网强行缩成文字不可读的缩略图。

局部视图仍可鼠标拖动、触摸拖动及双指缩放。通过下拉列表或地图选中其他机场时，局部视图聚焦该机场。重置按钮恢复当前视口的默认视角，而不改变所选机场。手动拖动不改变经营状态。

地图高度低于220像素时收起装饰性标题，保留简短拖拽说明。放大、缩小、重置三个按钮横向排列在图内，每个34×34像素，不能在视口顶部被裁切。下方原生机场选择始终作为全部城市的文字操作入口；WebGL失败时也可继续操作。

## 回归验证

纯相机计算测试覆盖完整地图、100像素高视口及偏远机场聚焦，核对城市字号和投影中心。浏览器在1440×900和844×390执行实际放大、缩小、重置，确认控件在视口内、所选机场可访问描述更新，并保存真实运行截图。延续计划明细收起时地图至少90像素高的验收条件。
