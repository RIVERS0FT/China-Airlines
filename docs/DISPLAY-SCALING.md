# 比例适配与 UI 缩放（2026-09-13）

替换此前按真实屏幕像素划分手机/桌面、最小44屏幕像素点击区的显示要求；游戏逻辑、存档格式和结算不变。

## 显示契约

以扣除刘海/安全区后的浏览器可用视口为准，不以设备型号、物理尺寸、像素密度分组。默认逻辑高度720。用户缩放系数 `u = 百分比 / 100`；实际缩放 `s = 可用高度 / 720 × u`；逻辑宽高为 `可用宽度 / s`、`720 / u`。因此同宽高比、同UI缩放下逻辑尺寸严格相同。1280×720与640×360默认共享1280×720逻辑布局。

UI 缩放75%–150%，步长5%，默认100%；设置内滑块、增减、预设和恢复默认均即时生效。独立键 `china-airlines:ui-scale:v1` 保存偏好，不写入经营存档；导入、重开不重置。非法值恢复默认，有限数字夹取范围并步长取整；存储不可用时本次仍可调整并显示提示。手机仍可自行调大界面，但这有意改变显示密度。

顶部、底部、客货、场景、地图标注和弹窗共用尺度。地图相机缩放级别独立；相机和路线草稿不能因调整尺寸而重建。所有按钮尺寸现在以逻辑像素验收，不再承诺小屏上44实际CSS像素；默认同构优先。竖屏在所有设备显示旋转提示。

## 实现与维护

`GameViewport` 测量外壳、安全区和窗口变化，建立命名容器 `game-viewport`，统一变换。构建期 PostCSS 将游戏样式中的尺寸/方向媒体查询转为该容器查询，将vh/vw类单位转换为逻辑单位。保留现有条件和值，但不再由物理屏幕触发。减少动画等环境偏好仍是媒体查询。只有外壳 `viewport.css` 不转换。新增游戏样式应使用逻辑px或同一命名容器，不得增加原生window.matchMedia尺寸判定。

原生dialog位于浏览器顶层，必须显式缩放并使用可用视口中心、逻辑宽高上限。地图指针与客货滚动距离通过显示/逻辑坐标换算；DPR仅用于canvas清晰度，不参与布局。设置更新不卸载App，不改变经营状态。

## 验收

覆盖同宽高比成倍分辨率、75/100/125/150%、异比横屏、竖屏恢复、缩放持久化与非法值、弹窗边界、地图点击/拖动、经营状态不变。旧44像素断言按相同逻辑尺寸换算；业务断言不得删除。真实设备文字栅格、系统字体和可用浏览器区域可能不同，不承诺跨系统逐像素完全一致。
