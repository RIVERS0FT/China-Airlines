# 机场浏览与调度入口 · v0.4 界面增量

## 目标与设计关系

补齐「先查看站点需求，再决定在哪装载或调入载具」的操作环节，航空化为机场目录、独立候机大厅和机场详情。原作证据与差异见 REPLICA-COVERAGE.md：本轮不声称机场目录、到离港列表的逐像素布局已经与原版核对。

此前主场景始终跟随当前飞机，导致已有空停机坪组件和无飞机装载限制不可从正常入口访问。本轮保留默认跟随机制，新增显式机场浏览模式。它是界面规则的扩充，不替换任何经济公式、机型、客源、人员、售机、存档格式或依赖版本。路线选择与城市直接通航规则以 DESIGN.md 第5节为准。包版本仍为0.4.0，保存格式4，数据库结构1。

## 操作和只读边界

底部「机场目录」显示已开放、未开放或全部机场。按城市、代码、区域搜索；大小写不敏感，忽略两端空格。空结果显示原因；不通过搜索、筛选、打开/关闭窗口刷新客源。目录卡显示真实人数、吨位、订单、中转、停靠和飞来航班，不把订单数当作人数。

点击卡片打开居中「机场详情」，包含候运去向、停靠飞机、飞来航班、从本机场起飞的在途航班。飞来/已起飞只是当前未完成航班，不是历史航班或真实航空时刻表。按预计到达时间和飞机ID排序。飞机flight非空时，即使airportId仍保存出发机场，也绝不能列为停靠；到达结算后才转为地面飞机，仍执行8秒周转。

中转只统计已经接受且来源不等于当前机场的地面订单；在来源地卸回的已接受订单不误记为中转。只读视图调用当前核心快照，不发钱、不删除订单。

「进入候机大厅」仅供已开放机场使用：场景固定查看该机场，只能选择该机场实际停靠的飞机。如果没有飞机，显示空停机坪和真实候运队列，装卸/派航禁用，不借用异地飞机。浏览期间飞机到达后可显示该架飞机，但周转及值勤限制仍生效。左右切机在浏览模式仅切换本机场的地面飞机；普通模式仍遍历全机队，可看飞行。

「返回所选飞机」结束机场浏览，回到此前选中飞机；机库或航班列表选择其他飞机，也回到跟随机制。购机默认交付到当前浏览的已开放机场，购买后当地新飞机可直接操作。地图规划必须使用实际选中飞机的出发地；从空机场进入地图时仍从原飞机的位置计算，不能瞬移。

「安排飞机飞来」只是进入地图并预选目标城市，不能自动装载或起飞。目标城市已解锁后无需另行开通航线；玩家仍须把它加入当前点击顺序路线并确认派航。在机场详情复用核心unlock/upgrade命令，成功保存后刷新资金与等级；失败不先显示成功。未开放机场无需求、无法进入候机大厅。满级明确显示，不显示无效升级按钮。

航网不常驻机场解锁/升级面板；选中未解锁城市会按需打开详情，已解锁城市可用「城市详情」打开。解锁/升级统一在详情内完成；关闭详情后保留尚未执行的路线草稿，从路线发起的解锁成功后可返回原地图并自动加入该城市。主动进入另一场景才按既有规则放弃地图本地草稿。无新增自动保存UI位置的字段；重载回到默认跟随机制。导入/售机导致选中ID或机场失效时，回退到存档中实际存在的飞机，不能创建或移动载具。

## 验收

保留全部既有测试。新增只读聚合、模糊/分类搜索、空机场、在途不能当停靠、到达/中转、售机/导入后失效选择、异地订单禁用的单元验证。浏览器执行1440×900、844×390和667×375空机场浏览，检查入口可见、无横向溢出、资金不变、无自动装载/派航，并覆盖异地购机后当地装载、实际起点派航、到离港刷新和从地图查看详情保留草稿。

原生dialog支持关闭按钮和Escape；长详情按窗口滚动，不挤占机场主画面。沿用竖屏提示、离线缓存、存档防覆盖。结果以实际Actions与截图为准，不以本文件代替测试通过回执。
