# 跨页面稳定导航（2026-09-15）

## 当前规则

按照“稳定不同页面下导航栏按钮位置、内部按钮左对齐”的要求，替换机场/公司页居中、地图页单独左下定位的布局差异，也替换“制定路线使用自动左边距推到最右侧”的旧规则。此增量优先于旧机场参考、公司组织、地图浏览文档中的导航几何描述；入口功能与顺序不变。

普通入口固定为地图、机场装载、机场目录、机队管理、飞机商店、公司组织、经营中心，从同一左侧起点按固定间距排列。制定路线只在机场页出现，紧接经营中心之后；它的显隐不改变前七个按钮的坐标、宽高或间距。选中、悬停、按下只改变视觉反馈，不平移按钮。

所有页面使用同一套逻辑尺寸：常规内边距12、间距8、普通按钮84×78、制定路线118×78；逻辑宽度不超过950的横屏普通按钮宽72、制定路线宽108。逻辑高度不超过600的横屏统一改为内边距8、间距5、普通按钮59×52、制定路线90×52。尺寸切换只依据现有逻辑视口，不依据设备类型或物理屏幕大小。

机场与公司组织页保留导航的固定布局高度，避免遮挡客货队列和人员内容；地图导航使用相同框体与按钮坐标，脱离布局流且完全透明，不减少地图画布高度。地图容器、内边距和间隙不接收指针，只有实际按钮接收点击；标签继续按真实按钮矩形避让，不能恢复整条底部禁区。制定路线仍隐藏全局导航。

## 实现边界

`src/ui/navigation.css` 为导航几何的统一入口，由 `src/main.tsx` 在既有页面样式之后载入。`map-browse.css` 仅保留浏览页搜索按钮样式，避免重复定义地图专属导航坐标。保留既有图标、单语言标题、角色入口、模态窗口、缩放、触控和离线契约。不更改 core、命令、资金、航班、订单、存档、数据库版本或依赖。
