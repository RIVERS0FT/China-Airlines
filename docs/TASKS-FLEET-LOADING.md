## 唯一任务入口

机场场景左上角永久保留“任务”入口，首行显示实际可领取数量，第二行优先显示可领取任务，否则显示进行中的任务及进度。无任务时仍能打开记录；不另设未读红点。首航未完成时其摘要继续使用真实引导进度；可领取奖励优先，不冒充首航奖励。

删除底部“运营任务”及场景右侧“航班/改装/奖励”，不增加“更多”替代按钮。底部仅机场装载、航线地图、机场目录、机队管理、飞机商店，右下保持制定路线。

任务中心统一展示原运营任务、成长任务、每日运输、七日启航礼、六区挑战，提供可领取/进行中/已领取筛选和奖励、进度、限制理由。有奖励时默认可领取，否则默认进行中。每日已领记录可回看；不补发已过期每日任务或签到礼，第七份礼的键与资格完全沿用核心。领取成功才改变金额、状态和数量，已领不可重复领取；关闭保持机场/飞机选择。领取后焦点返回当前筛选页签，原卡移至已领取。

经营中心不再重复展示“经营任务”页签。物资商店的投资赎回、物流园的贸易提交是消耗/交换型经营命令，仍留在相应业务页，不作为可领取任务计数。航班交付收入仍自动入账，不改为手工领奖。

## 机队管理

单一机队管理面板有“飞机/航班”两个页签。底部入口默认飞机，顶部机队概况及飞行机体快捷入口默认航班。航班页复用原清单的搜索、状态筛选、锁定金额和航段；点击一条航班打开对应飞机详情，点击“前往这架飞机”才关闭面板并前往实际机场/航班，避免浏览列表就改变场景。

飞机列表与详情显示状态、机场/航线、真实载荷和剩余时间；机上清单只读。改装、补能、随航调度员、出售继续在飞机详情内，通过原命令执行，原限制和费用不变。浏览、切换页签和查看航班均不得写经营状态。飞行中的机上清单仍标“已装机”，只禁止卸载。

## 客货三态

保留目的地分组、独立站牌、真实单体/历史聚合订单和横向候运地面。人物/货物不包进整块面板；增加小型状态底座和信息牌。信息牌固定价格、状态、动作/原因、业务类型四级，主状态只用“已装机/待装机/不可装”。

- 已装机：绿色底座与信息牌、勾号，卸载是次要动作。飞机满载、补能或飞行不得把机上订单错误改成不可装。
- 待装机：蓝色描边、加号和蓝色装机动作，正常清晰度。
- 不可装：灰色底座与信息牌、锁形图标，插画降饱和度，但价格和限制文字保持可读；动作禁用并显示具体原因。

不能仅靠颜色。中转保留和历史数量单独放置，不替代主状态。不额外创造“未装机”存档字段；UI 根据真实订单位置先判断是否属于当前飞机，再调用已有装卸限制投影。异步保存暂时禁用操作，但不伪造货舱/客舱不足。实际命令仍由核心重新验证。

装卸后原位变更，不能按状态立即重排；顶部载荷、机身示意及其他可装对象同步更新。目的地批量按钮无可装对象时不可点击，仍按核心批量规则装载。列表拖动或滑动不得触发误装卸；键盘激活不被之前的拖动吞掉。插画不得变成可拖拽图片。

## 机场导航图标与悬浮文字（2026-09-13）

机场底部五个普通入口和右下“制定路线”继续使用现有原创本地图标，不复制参考游戏素材。图标改为按钮的第一视觉主体，功能名不再占据独立文字行，而是绝对定位覆盖在图标下部前景；文字使用高对比浅黄/白色、深色描边与投影，必须在明暗图标和选中/禁用状态上保持可读。悬浮文字不接收指针事件，不能改变按钮实际命中区域、键盘焦点或无障碍名称。

普通入口仍保持机场装载、航线地图、机场目录、机队管理、飞机商店的固定顺序。桌面默认尺度下图标约占按钮高度的三分之二至四分之三；右下“制定路线”保留最高操作优先级，但由180px宽横向按钮收敛为独立大图标入口，宽度明显小于旧版，图标和文字仍采用同一叠层关系。禁用原因不替代主标题，也不得隐藏主图标；允许以按钮上缘的小型状态提示显示，同时完整理由继续通过 title/aria-describedby 暴露。

短横屏沿用同一 DOM 和同一叠层结构，只按逻辑尺寸缩小图标与文字；不得重新按设备像素切换另一套导航。75%–150% UI 缩放下文字必须保持单行、不截断、不超出按钮命中区域，制定路线始终位于最右侧且视觉优先级高于普通入口。
