# 统一页面、布局与容器

## 目标与范围

一套全局骨架、明确的页面导航、公共工作页容器和统一模态行为。地图与机场继续为场景，公司组织继续为树状工作区；不强制所有内容卡片化。此次不改 core、持久化、依赖、语言存档或飞机资源。

## 结构与职责

`GameViewport` 是唯一逻辑画布。`GameShell` 只组织 `TopStatusBar`、当前场景/工作页及 `MainNavigation`；`OverlayHost` 不创建新的定位或缩放容器。`App` 仍负责把只读快照、核心命令及页面回调组合起来。

`navigationReducer` 只有一个活动 page，同时记住返回所需的 scene。七个普通导航入口顺序固定：地图、机场装载、机场目录、机队管理、飞机商店、公司组织、经营中心。所有一级入口切换主工作区，不打开模态弹窗；制定路线仍为独立专注场景，隐藏普通 HUD 与导航。

`PageFrame` 负责工作页的边界、标题和主滚动容器；`PageHeader` 负责标题与右侧关闭/返回动作；`PageToolbar` 负责左对齐的内部工具排列；`PageBody` 只分配剩余空间；`ScrollRegion` 负责滚动与会话内滚动位置。页面外边距只由该容器负责，内部旧 `content-page` 不再叠加第二层页面留白。

组织树通过 tree 布局接入同一 PageFrame，保留内部按需招募、档案与树状空间，不再外套一层可滚动卡片。场景内容不强制显示 PageHeader，地图不恢复额外标题行。

## 导航与页面状态

普通导航固定尺寸、顺序、间距并左对齐；活动、悬停和按下状态不得改变几何。制定路线和起飞使用同一右侧定位与主操作尺寸。地图导航不占地图高度，容器空白不接受指针事件，只有真实按钮接受输入。

工作页关闭返回原场景而不是默认机场；地图场景保持挂载以保存视角，临时详情不重建路线草稿。工作页自身按需挂载，`PageStateProvider` 仅保存必要的 UI 偏好和滚动，不缓存所有页面 DOM、不修改游戏存档。保存的实体 ID 仍应由对应页面对照当前快照验证。

## 弹窗

设置、帮助、任务、机场详情及路线城市/明细使用 `GameDialog` 的同一原生 dialog 生命周期。标题和关闭按钮固定，正文单独滚动，取消键只关闭浮层。按需启用遮罩点击关闭，必须同时确认按下和点击都发生在实际遮罩，防止拖动误关。关闭恢复到仍存在且可见的触发控件；另一弹窗打开时不得抢走其焦点。

弹窗使用现有 viewport.css 的 top-layer 独立缩放；不移出 GameViewport、不重复缩放。原有业务确认、导入严格校验和备份保护保持。

## 样式边界

全局样式入口为 `styles/index.ts`，使用独立 CSS import 保持 PostCSS 的文件级逻辑/物理边界，不能用一个 CSS @import 合并文件而误转换 viewport.css。

`tokens.css` 维护间距、颜色、标题、控件和导航尺寸，断点使用逻辑容器。`styles/navigation.css` 是导航几何的唯一维护位置，原 navigation.css 删除。`layout.css` 只定义公共页面与弹窗结构。场景和美术的历史样式仍作为兼容层保留，不宣称本次已清空全部历史 polish/fixes；后续迁移需在对应模块验证后删除，不增加新的全局 fixes 文件。

公共组件只使用调用方已翻译的标题或现有翻译键，不新增语言判断。页面内部遗留的双语言分支不在本增量内重写，避免覆盖并行本地化工作。

## 验收

七个一级入口可直接互相切换且仅一个活动导航，工作页不是 dialog；标题、关闭、滚动、页签与导航不互相遮挡。地图视角与目录筛选在详情返回后保持。覆盖同有效比例桌面/手机及75%、100%、125%、150%缩放，保留导航穿透、真实装卸、制定路线、起飞、刷新恢复、导入导出、离线启动的既有业务断言。
