# 中华航空

中文、横屏、2D、单机航空运输经营Web/PWA。以《中华铁路》的场景结构和经营操作为复刻方向，铁路对象航空化，运行素材原创。本版本不是原作全部数值或像素级的一比一复刻。

## v0.4.0

机场装载、航网派航、飞行场景；12座机场、9种纯客/纯货/客货飞机；真实客货池、逐单装卸、手动中转和最终目的地单次交付；机库扩建、四项改装、最多5段运输计划。

新增随航调度员雇用/解聘、真实供给驱动的自动值勤、安全出售空机并释放机位、机队历史峰值任务，以及可跳过和恢复的分步起航引导。v1/v2/v3存档迁移为v4，保留旧在途收入和旧飞机的自动权限，不追扣费用。

开发前阅读 [AGENTS.md](AGENTS.md)、[设计](docs/DESIGN.md)和相关代码。[游玩指南](docs/PLAYING.md) · [v0.4操作说明](docs/PLAYING-V0.4.md) · [交付约定](docs/DELIVERY.md)。

## 运行与检查

Node.js >=22.12，沿用已锁定依赖。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

React负责界面、PixiJS负责航网、本地SVG负责机场和飞机。独立TypeScript核心负责订单、人员与时间事件，Dexie/IndexedDB负责主存档和备份，PWA负责离线缓存。无业务后端、账号、外部地图、在线字体或遥测。

生产输出dist/通过HTTPS静态托管或本地HTTP服务访问，不支持双击HTML。BASE_PATH=/China-Airlines/用于项目子路径构建。主分支合并后按已有Pages流程完整复验，再发布同一产物；需要可用站点配置和权限。源码合并与静态包生成不等于网站已经上线。

所有机型、雇用/售机价格、游戏单位和地图坐标均为本作配置，不用于真实航空导航或调度，与现实航空公司无关联。

## 界面对照增量

装载区增加可键盘操作的左右翻页、原创旅客行李/货运车表现与明确的不可装卸原因；地图显示单段/多段草稿的方向、访问顺序和不可飞航段。草稿不扣费也不保存。详见 [界面参照与验收](docs/UI-REFERENCE.md)。
