# 中华航空

中文、横屏优先、2D 场景与球面航网的单机航空运输经营 Web/PWA。产品目标是保留《中华铁路》的场景式装载、运输规划和载具经营习惯，并使用原创航空题材素材；当前实现不是原作全部功能、数值或画面的完整一比一复刻。

## 当前玩法

- 在机场接受真实旅客和货物订单，逐单或按目的地装机；中转不结算，到最终目的地只结算一次。
- 在球面航网上选择最多 5 个航段；航程、机场等级、资金、能量、周转和人员状态共同约束起飞。
- 经营 13 种可购机型及初航赠机，进行改装、编队、进化、补能、人员培养、生产和贸易。
- 所有经营写入由 `src/core` 完成；React、PixiJS、Three.js 和持久化层只发送命令或读取快照。
- 到达、补能、生产和离线收益按时间事件结算，离线推进最多 8 小时，不依赖动画回调。

当前存档格式只支持 `version: 10`，IndexedDB 结构版本为 1。导入会严格校验完整状态；版本不符或数据损坏时拒绝导入，不覆盖当前有效进度。项目不保留旧存档迁移器、旧目录快照或旧版测试夹具。

运输收入和成本公式见 [当前设计](docs/DESIGN.md)，操作见 [游玩指南](docs/PLAYING.md)，原作证据与适配边界见 [APK 证据](docs/APK-EVIDENCE.md)。

## 开发与验证

要求 Node.js 22.12 或更高版本，并使用锁定依赖：

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

子路径构建使用 `BASE_PATH=/China-Airlines/`。生产产物必须通过 HTTP/HTTPS 托管，不能直接双击 HTML。提交前同时验证根路径与子路径构建、桌面和手机横屏、竖屏提示、刷新恢复、导入导出与离线启动。

开发约定见 [AGENTS.md](AGENTS.md)，部署及交付边界见 [DELIVERY.md](docs/DELIVERY.md)。源码完成、构建成功与站点部署是三个独立结果；没有部署回执时不得宣称已上线。

地图坐标、机型数值和价格均为游戏化配置，不用于真实航空导航、调度或载重计算，本项目与现实航空公司无关联。
