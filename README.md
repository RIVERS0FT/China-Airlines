# 中华航空

中文、横屏、2D、单机航空运输经营Web/PWA。以《中华铁路》的场景结构和经营操作为复刻方向，铁路对象航空化，运行素材原创。本版本不是原作全部数值或像素级的一比一复刻。

## v0.5.0

机场装载、航网派航、飞行场景；12座机场、9种纯客/纯货/客货飞机；真实客货池、逐单装卸、手动中转和最终目的地单次交付；机库扩建、四项改装、最多5段运输路线。

地图路线改为按城市点击顺序形成：飞机当前机场为起点，依次点击已解锁城市即可组成1至5段路线。城市解锁后可直接前往，不再另收航线建设费，也没有“单段/多段”模式切换。历史 `routes` 仅保留为旧存档、在途航班和自动值勤的兼容/运营记录。

新增随航调度员雇用/解聘、真实供给驱动的自动值勤、安全出售空机并释放机位、机队历史峰值任务，以及可跳过和恢复的分步起航引导。v1/v2/v3/v4存档迁移为v5，保留旧在途收入和旧飞机的自动权限，不追扣费用。

开发前阅读 [AGENTS.md](AGENTS.md)、[设计](docs/DESIGN.md)和相关代码。[复刻覆盖与缺口](docs/REPLICA-COVERAGE.md) · [游玩指南](docs/PLAYING.md) · [v0.4操作说明](docs/PLAYING-V0.4.md) · [交付约定](docs/DELIVERY.md)。

## 运行与检查

Node.js >=22.12，沿用已锁定依赖。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

React负责界面、PixiJS负责航网、本地SVG负责机场和飞机。独立TypeScript核心负责订单、人员与时间事件，Dexie/IndexedDB负责主存档和备份，PWA负责离线缓存。无业务后端、账号、外部地图、在线字体或遥测。

生产输出dist/通过HTTPS静态托管或本地HTTP服务访问，不支持双击HTML。BASE_PATH=/China-Airlines/用于项目子路径构建。主分支合并后按已有Pages流程完整复验，再发布同一产物；需要可用站点配置和权限。源码合并与静态包生成不等于网站已经上线。

所有机型、雇用/售机价格、游戏单位和地图坐标均为本作配置，不用于真实航空导航或调度，与现实航空公司无关联。

## 界面对照增量

装载区增加可键盘操作的左右翻页、原创旅客行李/货运车表现与明确的不可装卸原因；地图显示按城市点击顺序形成的路线草稿、方向、访问顺序和不可飞航段。草稿不扣费也不保存；首次实际飞过的城市对会作为运营记录显示在航网上，但不是付费解锁条件。详见 [界面参照与验收](docs/UI-REFERENCE.md)。

## 机场浏览增量

底部机场目录支持搜索与开放状态筛选。机场详情显示候运去向、停靠飞机、飞来和已起飞航班。进入没有停靠飞机的机场只能浏览，不会把异地飞机移来；购机默认可交付当前机场，再操作当地新机。地图打开详情不清空草稿。参见 [机场浏览规则](docs/AIRPORT-BROWSING.md)。该机场浏览阶段未调整经营公式；v0.5新增能量约束，当前存档格式5。

## 航班运行增量

顶部机队入口打开运行表，筛选待命/飞行状态并切换飞机；飞行页和地图显示当前航班锁定收支，不因浏览其他机场重新计价。机库默认跟随当前查看飞机。保留独立空机场浏览；在运行表选择飞机会退出固定机场浏览，所有位置和金额仍由核心决定。详细边界见 [运行信息规则](docs/FLIGHT-OPERATIONS.md)，证据补充见 [逐项研究清单](docs/REPLICATION-MATRIX.md)。

## 能量预算增量

飞行每60秒需要1点，起飞按整数秒预留当前航段，能量不足不扣费、不起飞；自动或多段运输在后续能量不足时停在实际机场并保留客货。机库可以安排或取消地勤补能，补能中的飞机不会被列为待命。旧版在途航班不追扣，旧订单和资金不重算。

基础240点取自2016攻略示例，统一容量、按秒预留和120秒免费地勤补满是本作声明的基础档/适配规则，**不是全部原版车型或恢复数值已经还原**。证据与差异详见 [能量规则](docs/ENERGY.md)。包0.5.0、存档5、数据库结构1；更新前导出备份。
