# 中华航空

中文、横屏优先、2D 场景与球面航网的单机航空运输经营 Web/PWA。产品目标是保留《中华铁路》的场景式装载、运输规划和载具经营习惯，并使用原创航空题材素材；当前实现不是原作全部功能、数值或画面的完整一比一复刻。

## 当前玩法

- 在机场接受真实旅客和货物订单，逐单或按目的地装机；中转不结算，到最终目的地只结算一次。
- 在球面航网上选择最多 12 个航段；航线沿球面大圆路径绘制，在途飞机统一使用透明2D俯视图，以原始宽高比作为正面基准，按当地球面切平面作仿射投影，靠近球体侧面自然倾斜缩短，机头沿航线前向、不镜像，背面隐藏。静止地图按需重绘，可见飞行动画上限30 fps；航程、机场等级、资金、能量、周转和人员状态共同约束起飞。
- 经营 10 种可购机型，进行改装、编队、进化、补能、人员培养、生产和贸易。
- 公司组织的人才市场提供总经理、飞行部与地勤部经理及专员候选，15名候选每30分钟整批更新并显示倒计时。运输与总部岗位最多雇佣15名员工，业务团队可继续扩张，招募后自动分配飞机、机场或经理岗位；人物卡显示分配目标，无可用空位或人数已满时禁用招募且不扣费。可继续调岗、培训和续约，市场更新不改变已雇佣人员。总经理对直属业务团队提供管理加成，运输结算不变；无需招募经理也能手动经营。
- 所有经营写入由 `src/core` 完成；React、PixiJS 和持久化层只发送命令或读取快照。
- 到达、补能、生产和离线收益按时间事件结算，离线推进最多 8 小时，不依赖动画回调。新增业务收入只累计前台时段，不参与离线补算。

当前存档格式只支持 `version: 16`，IndexedDB 结构版本为 1。旧 `version: 14` 及其他版本拒绝读取，不自动迁移；已有旧版进度会进入恢复界面。导入会严格校验完整状态；版本不符或数据损坏时拒绝导入，不覆盖当前有效进度或备份。项目不保留旧存档迁移器、旧目录快照或旧版测试夹具。

运输收入和成本公式见 [当前设计](docs/DESIGN.md)，操作见 [游玩指南](docs/PLAYING.md)，原作证据与适配边界见 [APK 证据](docs/APK-EVIDENCE.md)。

## 开发与验证

要求 Node.js 22.12 或更高版本，并使用锁定依赖。安装和启动：

```sh
npm ci
npm run dev
```

单项修改只运行受影响的定向测试，不运行全量套件；生产代码变化先完成类型检查和对应路径构建，再运行相关 Playwright 文件。测试按单元功能、跨模块流程、完整游戏流程和界面回归分层，详见 [测试约定](docs/TESTING.md)。推送时执行完整测试，入口如下：

```sh
npm run typecheck
npm test
npm run build
node scripts/prepare-browser.mjs
npm run test:e2e
```

`npm test` 与 `npm run test:e2e` 执行完整集合，推送后由CI执行一次相对路径构建和一次完整浏览器验收，不再重复运行根路径测试。锁定 Chromium、系统依赖和中文字体检查见 [浏览器 Runner](docs/BROWSER-RUNNER.md)。

项目始终使用 `base: ./` 构建，通过 riversoft.top HTTPS 托管发布 API 上传和提交，公开地址、路径与首页展示由平台决定。禁止 SSH 直接部署；旧工作流已停用，同名项目须先在平台完成迁移。发布后必须验证首页目录、全部静态文件及离线/存档浏览器流程。若平台分配新域名，旧地址的存档需要导出后在新地址导入。游戏仓库不自动发布 GitHub Pages；产物需通过 HTTP/HTTPS 托管，不能直接双击 HTML。

开发约定见 [AGENTS.md](AGENTS.md)，部署及交付边界见 [DELIVERY.md](docs/DELIVERY.md)。源码完成、构建成功与站点部署是三个独立结果；没有部署回执时不得宣称已上线。

地图坐标、机型数值和价格均为游戏化配置，地图不是导航资料；本项目与现实航空公司无关联。

新增城市业务团队、真实每秒净收入、招聘、岗位扩建和业务培养，规则与数值见 [公司业务](docs/COMPANY-BUSINESS.md)。业务员工使用既有唯一员工名单，岗位不计入运输人员15人限制。仅前台时段累计业务净收入，不新增离线业务奖励。当前存档v16必须包含business完整状态；旧v14及其他版本拒绝，不自动迁移、不覆盖主档或备份。
